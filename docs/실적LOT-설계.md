# 실적 LOT · 투입 LOT 연결 설계

> 작성일 : 2026-11-11 · 상태 : **설계 확정 ( 미착수 )** — 사용자 확정 11-11 ( §9 결정 5가지 포함 )

## 1. 왜

| 지금 | 바꾸려는 것 |
|---|---|
| 원자재출고 공정을 **[완료]** 해야 다음 공정에 실적을 넣는다 | 자재가 **1건이라도 나갔으면** 다음 공정을 진행한다 ( 얼마나 만들 수 있는지는 정확히 셀 수 없다 ) |
| 생산 LOT = **작업지시 줄 1개에 1개** ( 지시 저장 때 발급 · 실적을 몇 번 넣어도 같은 LOT ) | **실적 1건마다 LOT** · 각 실적이 어느 자재 LOT · 앞 공정 LOT 로 만들어졌는지 사람이 골라 잇는다 |

## 3. 원자재출고 완료 전 다음 공정 진행

- 기준 = **작업지시 품목 줄**( 줄마다 공정이 따로 ) — 그 줄에 자재 출고가 **1건 이상**( 취소 제외 )이면 원자재출고 공정이 완료 전이어도 다음 공정 실적을 받는다
- **원자재출고 공정만** 해당 — 검사 공정 · 그 밖의 시스템 공정은 지금처럼 완료돼야 다음으로
- 수량 상한은 두지 않는다 — 첫 수량 공정의 기준은 지금처럼 지시 수량( 넘으면 경고 · 초과 생산 )
- 원자재출고 공정은 첫 출고 때 **진행** · [완료]는 지금처럼 사람이( 덜 나간 자재가 있으면 확인 )
- 고칠 곳 : `OpResultService::workBlock()` — 앞 공정이 원자재출고( `Process::isRmOut` )이고 설정이 켜져 있으면 `완료` 대신 `출고 1건 이상`으로 판단 · 원자재출고 공정 상태( 첫 출고 때 RUN ) · 화면의 막힘 문구

## 4. 실적 LOT ( 공정 LOT 추적 켬 )

- **모든 수량 공정**에서 실적 1건 = LOT 1개 ( 실적 저장 때 발급 )
- 마지막 공정의 실적 LOT = **제품 LOT** → 제품 입고 · 재고 · 출하 피킹이 그 LOT 단위 ( 지금의 "실적마다 부분 입고"가 실적 LOT 로 들어간다 )
- 중간 공정의 실적 LOT = 재고가 아닌 **공정 사이 재공 LOT**
- **검사 공정** : 새 LOT 없음 — 검사받은 LOT 를 그대로 넘긴다 ( 뒤 공정은 검사 앞 공정의 LOT 를 고른다 )
- **외주 공정** : 외주 **입고** 때 새 LOT · 외주로 **출고**한 앞 공정 LOT 와 연결
- 실적 취소 : 그 실적 LOT 가 뒤 공정 실적에 연결돼 있으면 막는다 ( 연결을 먼저 해제 ) · 취소된 실적의 LOT 는 미사용으로 남긴다( 번호 재사용 없음 )
- 작업지시의 LOT( `work_order.lot_idx` ) : 켬이면 **발급하지 않는다** — 실적 LOT 만 ( §9-2 )
- LOT 번호 : 마지막 공정( 제품 LOT ) = 지금 LOT 규칙 그대로 · 중간 공정 = 작업지시 번호 + 공정 + 순번 ( §9-1 )

## 5. 투입 LOT 연결 ( 공정 LOT 추적 켬 · 필수 · 사람이 고름 )

- 자동으로 고르지 않는다 — 실적 입력 칸에 **투입 LOT** 선택( 여러 개 · LOT 마다 **수량** 입력 )
  - 자재가 투입되는 공정( BOM 투입 지점 — 없으면 첫 수량 공정 ) : 그 품목 줄에 **출고된 자재 LOT**
  - 그다음 공정 : **앞 공정의 실적 LOT** ( 사이에 검사 공정이 있으면 그 앞 공정 )
  - 둘 다 해당하는 공정( 중간에 자재가 또 들어감 )은 둘 다 고른다
- **나중에 추가 · 해제** — 이미 저장한 실적 LOT 에도 연결을 더하거나 뺀다
  ```
  원자재 MT-A 1개 출고 → 가공 실적 30 ( LOT P20-001 ← MT-A )
  → 원자재 MT-B 추가 출고 → P20-001 에 MT-B 연결 추가 ( P20-001 ← MT-A · MT-B )
  ```
- 수량 검사는 **경고만** ( 막지 않음 )
  - 한 앞 공정 LOT 에서 끌어간 수량 합 > 그 LOT 의 실적 수량
  - 자재 LOT 연결 수량 > 그 LOT 의 출고 수량( 그 지시 )
- 연결 수량은 **추적용 기록** — 재고 · 사용처리에 영향 없음 ( §6 )
- 필수 : 켬이면 투입 LOT 없이 실적 저장 막음 · 끔이면 칸이 보이지 않는다

## 6. 재고 · 사용처리 — 바꾸지 않는다

- 출고 = 창고 재고 − · 지시 보유 + / 사용처리 = 지금 정책 그대로( `material.consume_timing` — **출고 시** 권장 : 출고하면 곧 사용 )
- 남은 자재는 **반납**( 같은 LOT 로 창고 + · "덜 썼다" ) — 반납한 만큼만 재고가 돌아온다
- 연결 수량으로 사용량을 나누지 않는다 ( BOM 이 많거나 소수점 자재면 현장에서 셀 수 없다 — 11-11 사용자 결정 )

## 7. 데이터 ( 초안 — 착수 때 확정 )

| 무엇 | 안 |

| 투입 연결 | 새 표 `work_order_run_input` — `run_idx` · `input_type`( MATERIAL 자재 LOT / RUN 앞 공정 실적 LOT / SUBCON 외주 입고 LOT ) · `lot_idx` · `qty` · 등록자 · 일시 · `is_canceled` · 해제한 사람 · 해제 일시 ( §9-4 ) |

## 9. 결정 ( 11-11 사용자 확정 — 전부 제안대로 )

| # | 항목 | 결정 |
|---|---|---|
| 1 | 공정 LOT 번호 | 마지막 공정( 제품 LOT ) = 지금 LOT 규칙 그대로 · 중간 공정 = 작업지시 번호 + 공정 + 순번 ( 예 : WO-261111-001-01-P20-001 ) |
| 2 | 켬일 때 작업지시 LOT | 발급하지 않는다 — 실적 LOT 만 ( 지시 화면의 LOT 칸은 '실적별' ) |
| 3 | 줄 완료 때 남은 수량 입고 | 마지막 수량 공정의 실적 LOT 별로 나눠 입고 ( 검사가 있으면 합격분 ) |
| 4 | 연결 해제 | 지우지 않고 취소 표시 ( 해제한 사람 · 일시 ) — 추적 화면에는 안 보이고 이력으로만 |
| 5 | 운영 중 설정 변경 | 지시에 LOT 방식을 저장 — 진행 중인 지시는 만들 때의 방식으로 끝까지 ( 섞이지 않게 · 막지 않음 ) |

## 10. LOT 추적 화면 ( 11-11 사용자 확인 )

그대로 붙이면 : 공정마다 단계가 늘어 **단계 상한 10** 에 걸리고( 공정 5 반제품 + 공정 5 완제품 ≈ 13단계 ) · 실적 수만큼 노드가 늘어 **노드 상한 300** 에 닿고 · 다대다 연결로 선이 엉킨다 → 아래처럼

1. **기본 = 요약 보기 · 필요할 때 공정 펼치기**
   ```
   요약 ( 기본 ) :  자재 LOT MT-A ──▶ [ 작업지시 WO-…-01 ] ──▶ 제품 LOT P30-001 · P30-002
                                       └ [ 공정 펼치기 ]
   펼침 :          자재 LOT MT-A ──▶ P20-001 ──▶ P30-001
                                └──▶ P20-002 ──▶ P30-002
   ```
   - 요약도 연결을 따라 **실제로 이어진 제품 LOT 만** ( 지금은 그 지시의 제품 LOT 전부 )
   - 공정 LOT 는 지시 노드의 [공정 펼치기] 를 누를 때만 그 지시 안에서 그린다
2. **단계 상한** : 지시 안의 공정 LOT 단계는 세지 않는다 — 지시 ↔ LOT 경계만 센다
3. **펼친 공정 LOT** : 지시별 배경 상자로 묶고 공정 순서대로 줄을 맞춘다 · 선 위에 연결 수량
4. **오른쪽 패널 [실적] 탭** : 공정 LOT 노드 → 공정 · 작업자 · 일시 · 설비 · 투입 LOT( 수량 ) · 연결한 사람
5. 그 밖
   - 검사 공정은 노드 없음 — LOT 노드에 '검사 합격' 표시
   - 외주 입고 LOT 노드에 외주처
   - 해제한 연결은 그리지 않는다( §9-4 )
   - LOT 방식이 '지시 1 LOT' 인 지시는 지금 모양 그대로 ( 섞여도 된다 )
   - 연결 표 인덱스 `lot_idx` · `run_idx` ( 단계마다 한 번 조회 )
