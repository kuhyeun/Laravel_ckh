## 수주관리
- 기본기능 : 수주관리 리스트, 수주등록, 수주삭제, 전자결재연동, 수주이력
- 수주는 1건에 품목 여러건 등록, 특정 프로젝트(품목, 모델 등 고정적이지 않음)에 대한 반복적 수주가 있음
- 수주관리 리스트는 기본 수주별로 표시하나 클릭시 트리형태로 품목이 표시됨
- 품목은 개별로 납품일이 다를 수 있음
- 특정 프로젝트에 대한 반복적 수주는 정기수주로 명칭, 스케줄을 정하거나 상시로 일정을 정할 수 있음. 해당 일정마다 생산계획을 잡거나, 작업지시를 내릴 수 있음
- 수주건당 전자 결재 진행, 결재는 폼을 작성하여 올림, 양식을 가지는 editor
- 수주이력 페이지는 1년단위 기간에 대한 수주의 수주수량, 생산실적, 납품실적을 한눈에 확인 가능한 리스트로 표시
- 수주별로 진행상황 하위폼목 모두 진행상태 확인할 수 있도록 기능 구성
	수주명 | 품목명 | 수량 | 원자재입고(date) | 원자재출고(date) | 1공정(s/e/검사badge) | 2공정(s/e) | 3공정(s/e) | 출하검사(date) | 출하(date)
- 전자결재 : 수주들어오면 수주 결재 연동해서 진행

- 출고 : 생산전 자재(원자재/부자재) 출고 ( 선점 ), 생산실적관리에서 원자재 출고 표시/원자재 출고 가능
- 원자재/부자재는 생산전 필요시점에 사용처리(원자재는 생산공정시작전/외주출고전(사급자재) 자동차감 가능*설정)

- 원자재 환봉/코일/판소재 일부사용 및 재입고 처리, 재입고처리 후 바코드 발행

- 수불 기록에 대해서 정의 필요**

## 출하관리
- 출하품관리(판매자재, 생산제품/부품)
- 출하가 가능한 품목 관리, 출하대기품
- 출하관리 - 수주선택하고 출하, 품목 선택 출하(수주엮인 것은 안됨)
- 출하대기에서 출고후 출하 완료하면 사용처리 ( 선점 )

- 공정라우팅에서 생산계획잡을때 바로 발주들어가서 생산완료되면 바로 출하까지 처리되도록 - 생산 전후 행위 미리 지정해 놓을 수 있는지**

	입고, 공정완료시 창고입고에서 선택 발행, 재입고 후 발행
- 동일한 바코드 번호로 발행 가능 : 자재 사용 및 출하때 한번 찍을때 동일 바코드에서 하나씩 선택
- 바코드 리스트 및 출력(바코드와 일부 정보)
- 기본 바코드 라벨지 사이즈 / 분할에 대해 사이즈 준비, 몇장씩 프린트할지 선택 필요, 프린트 여부/횟수 기록, 프린트 여부로 필터링
- 폐기 : 폐기사유 입력
- 미리 선발행하고 입고 또는 공정시 발행한 바코드 선택 가능
