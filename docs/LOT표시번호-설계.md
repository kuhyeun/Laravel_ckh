# LOT 표시 번호 ( lot_title ) 설계

> 11-24 · 대외 LOT 등으로 LOT 번호를 바꿔 보여야 할 때 — 원번호( `lot_no` )는 그대로 두고 표시 번호를 따로 둔다

## 1. 데이터

| 칸 | 뜻 |
|---|---|
| `lot.lot_no` | **원번호** — 채번 규칙으로 만든 번호 · 내부 연결 · 이미 발행한 라벨 바코드 · 정렬 · 채번 중복 검사 |
| `lot.lot_title` ( nullable · 60자 ) | **표시 번호** — 비어 있으면 원번호 |
| `lot.external_lot_no` | 공급처 LOT ( 구매처가 붙인 번호 — 그대로 따로 ) |

**표시 번호 = `lot_title` 이 있으면 그것 · 없으면 `lot_no`**

## 2. 적용

- **표시 · 인쇄 전부** : 재고 · 출고 · 실적 · 검사 · 출하 · 추적 목록 · 문서 양식 · 라벨의 LOT 칸 — 서버가 LOT 번호를 내보낼 때 표시 번호로
  - Eloquent : `Lot` 모델의 `lot_no` 를 읽으면 표시 번호 ( 관계로 부를 때 `'lot:lot_idx,lot_no,lot_title'` ) · 원번호 = `original_no`
  - 쿼리 빌더 : `Lot::showSql('l') . ' as lot_no'`
- **검색** : LOT 검색은 원번호 · 표시 번호 둘 다 ( `Lot::whereNoLike()` )
- **채번 · 내부 연결 · 정렬** : 원번호 그대로

## 3. 표시 번호 바꾸기

- 어디서 : **재고관리 · 제품재고 LOT 이력 창** · **물품표 인쇄 미리보기** ( `LotTitleEditor` )
- 권한 : 자재 LOT = 재고관리 · 물품표 쓰기 / 제품 LOT = 제품재고 · 현품표 쓰기
- 비우거나 원번호와 같으면 원번호로 ( `lot_title = NULL` )
- 다른 LOT 의 원번호 · 표시 번호와 겹치면 막는다 — 스캔 · 검색이 한 LOT 으로만 찾아가게

## 4. 라벨 · 바코드

- **이미 발행한 라벨** : 발행 당시 번호 그대로 ( `barcode_label.barcode_no` ) — 붙어 있는 라벨도 계속 스캔
- **새로 발행** : 바코드 번호 = 표시 번호 ( `lot_title` → `lot_no` )
- **물품표 미리보기 [새로 발행]** : 바코드가 지금 번호와 다르면 알리고 → 지금 번호로 새 라벨 ( 양식 · 장수 · 한 장 수량은 최근 라벨 그대로 ) · **예전 라벨은 그대로 유효** ( A안 )
- **스캔** : 라벨 바코드 번호 → 라벨 → LOT · 라벨이 없으면 LOT 원번호 · 표시 번호로

## 5. 주의

- LOT 번호를 DB 에서 직접 바꾸면 라벨 기록( `barcode_no` )은 따라 바뀌지 않는다 — 표시 번호 기능으로 바꾸고 필요하면 [새로 발행]
- 출하 라벨( 현품표 7005 )은 출하 줄 번호가 바코드 — LOT 번호 변경 대상이 아니다 ( 제품 LOT 번호는 제품재고에서 )
