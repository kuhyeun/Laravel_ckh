# ADR 0006. 품목은 단독 판매 여부로 나눈다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/ERD.md` §6

## 배경

반제품과 완제품을 **BOM 위치**로 나누려 했다. 하위에 있으면 반제품이라는 규칙이다.
그런데 세트의 구성품은 세트로도 팔리고 **낱개로도 팔린다.** BOM 하위라고 반제품이라 부르면
그 품목의 단가·거래·재고가 전부 어긋난다.

## 검토한 대안

| 기준 | 문제 |
|---|---|
| BOM 하위 여부 | 같은 물건이 어느 BOM에 걸리느냐로 성격이 바뀐다 |
| 공정 수 | 한 공정짜리 완제품이 있다 |
| **단독으로 파는가** | 채택 |

## 결정

```
고객에게 단독으로 팔리는가   → 예: FINISHED
사내 공정에서만 소비되는가   → 예: SEMI
BOM에서 하위인가             → 판단 근거가 아님
```

**세트는 만들어지는 품목이다.** 미조립 세트(`SET`)는 **포장공정 하나짜리 라우팅**을
가진 완제품이고, 조립품은 BOM·단가·품번·라우팅이 다르므로 **별개 품목**이다.

## 결과

- 구성품이 완제품으로 등록돼도 이상하지 않다
- 세트도 작업지시가 나가고 LOT이 생긴다 — 특수 처리가 없다
- `SET`에 라우팅이 없으면 경고한다. 포장도 공정이다
