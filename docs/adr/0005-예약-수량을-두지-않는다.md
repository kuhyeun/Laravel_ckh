# ADR 0005. 예약 수량을 두지 않는다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/재고-수불-설계.md`

## 배경

처음에는 `stock_balance.reserved_qty`를 두고 `가용 = qty - reserved_qty`로 잡았다.
그런데 이 현장에서 **출고는 실제 차감**이다. 출고하는 순간 이미 `qty`가 줄어 있다.
예약 수량은 아무것도 막지 않으면서 **두 번 빼는 위험**만 만든다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| `reserved_qty` 유지 | 출고에서 이미 뺐는데 또 잡아 둔다. **이중 차감** |
| 예약 전표를 따로 | 원장에 실물 이동이 아닌 행이 섞인다 |
| **예약을 없애고 작업지시별 보유를 따로 본다** | 채택 |

## 결정

`reserved_qty`를 삭제한다. **가용 수량은 `qty` 그 자체다.**

대신 `wo_stock`(작업지시 × 품목 × LOT)을 둔다 —
**출고됐지만 아직 안 쓴 자재**가 어느 지시에 붙어 있는지를 여기서 본다.

## 결과

- 가용 수량 계산이 단순해진다. 뺄 것이 없다
- *"출고는 했는데 아직 안 쓴 것"*이 화면에 보인다 — 예전에는 안 보였다
- 예약 개념이 필요한 업무(사전 할당)가 나중에 생기면 **별도 설계**가 필요하다
