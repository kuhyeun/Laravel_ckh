# ADR 0012. 작업지시는 수주에서만 나오지 않는다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/ERD.md` §9

## 배경

작업지시를 수주 라인에 1:1로 매달았다. 그런데 **안전재고를 보고 미리 내리는 지시**가 있다.
어느 시점에 모자라는지 보고 한꺼번에 발행한다. 수주가 없으므로 매달 곳이 없다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 가짜 수주를 만든다 | 팔리지 않은 것이 수주 잔량에 잡힌다 |
| 별도 테이블 | 작업지시 화면·실적·LOT이 전부 두 벌이 된다 |
| **발행 근거를 컬럼으로** | 채택 |

## 결정

`work_order.source` = `ORDER` / `STOCK` / `MANUAL`,
`sales_order_line_id`는 **`NULL`을 허용**한다.

부족 시점은 **버킷(일·주·월)**으로 전개하고,
**커버 구간 = 리드타임 + 발주 주기**로 잡는다.
지시 수량은 `MOQ` 통과 후 `unit_round` 배수로 올린다.
**이미 늦은 것은 오늘로** 당긴다 — 과거에 발주할 수 없다.

## 결과

- 재고 기반 지시는 **납품처가 없다.** LOT 번호에 거래처를 넣을 수 없는 이유가 된다 (ADR 0017)
- 버킷을 주로 보느냐 월로 보느냐에 따라 **부족 시점이 달라진다** — 정책으로 뺐다
- 확정 수주만 계산에 넣는다
