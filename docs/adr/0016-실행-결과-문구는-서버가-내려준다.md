# ADR 0016. 실행 결과 문구는 서버가 내려준다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/프로그램-스펙.md` §6.1

## 배경

*"저장했습니다"*를 화면마다 쓰면 같은 상황에 다른 말이 뜬다.
더 나쁜 것은 **경고**다. 저장은 됐지만 알려야 할 것이 있는 경우를 화면이 판단하면
화면마다 다르게 군다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 화면이 문구를 정한다 | 같은 동작에 화면마다 다른 말 |
| 경고를 4xx로 내린다 | **화면이 롤백한다.** 저장은 됐는데 안 된 것처럼 보인다 |
| **응답 봉투에 `notice`를 싣는다** | 채택 |

## 결정

```ts
interface ApiNotice { level:'success'|'info'|'warn'|'error'; message; detail?; code?; sticky? }
interface ApiResponse<T> { data: T; meta?; notice?: ApiNotice }
```

**`W_` 경고는 200에 실려 온다.** 성공·정보는 3초 후 사라지고,
경고·오류는 **수동으로 닫는다.**

## 결과

- 문구를 바꾸려면 **서버 한 곳**만 고친다
- 화면은 `notice`를 그대로 띄운다. 판단하지 않는다
- `notice`가 없으면 조용히 지나간다 — 모든 응답에 넣을 필요가 없다
