# ADR 0004. 시간을 발생과 기록 두 축으로 적는다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/재고-수불-설계.md`

## 배경

현장은 먼저 움직이고 전산은 나중에 따라온다. 어제 출고한 것을 오늘 입력하는 일이
예외가 아니라 **정상 업무**다. 시각이 하나면 둘 중 하나를 포기해야 한다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 입력 시각만 | 어제 나간 물건이 **오늘 나간 것**이 된다. 일자별 집계가 틀린다 |
| 발생 시각만 | 누가 언제 입력했는지 모른다. **소급 입력을 감사할 수 없다** |
| **둘 다** | 채택 |

## 결정

모든 수불 전표에 두 시각을 적는다.

| 컬럼 | 뜻 |
|---|---|
| `occurred_at` | **물리적으로 언제 일어났나** — 집계와 마감의 기준 |
| `recorded_at` | **언제 전산에 들어왔나** — 감사와 추적의 기준 |

**소급은 정상이다.** 막지 않고, 얼마나 거슬러 갈 수 있는지만 정책으로 제한한다.

## 결과

- 일자별 집계는 `occurred_at`을, 감사 로그는 `recorded_at`을 본다 — **섞으면 안 된다**
- 마감된 기간으로 소급하면 거부한다. 그 판단도 `occurred_at` 기준
- 조회 화면은 어느 축으로 보는지 **명시해야 한다**
