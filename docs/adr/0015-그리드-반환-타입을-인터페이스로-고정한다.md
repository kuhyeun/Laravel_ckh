# ADR 0015. 그리드 반환 타입을 인터페이스로 고정한다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/프로그램-스펙.md` §12.2

## 배경

같은 데이터를 그리드에도 쓰고 API로도 쓴다. 서버 응답을 그리드 라이브러리 모양으로
내려 주면 **그리드에 종속된 응답**이 되고, 나중에 그리드를 바꾸면 API가 따라 바뀐다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 서버가 tui-grid 형식으로 내려준다 | **API가 UI 라이브러리에 묶인다** |
| 화면마다 변환 | 같은 코드가 30벌 생긴다 |
| **도메인 타입 위에 그리드를 씌운다** | 채택 |

## 결정

```ts
interface StockRow { lotId; itemCd; qty; ext: Record<string, …> }  // 서버 응답 = 도메인
interface GridResult<T> { rows: T[]; total; page; perPage }        // 봉투 고정
interface MesColumn<T> { key: (keyof T & string) | `ext.${string}`; header; … }
```

**`tui-grid`를 `import` 하는 파일은 `MesGrid.vue` 하나**로 제한하고 린트로 막는다.

## 결과

- 같은 `rows`를 그리드 · 엑셀 · 인쇄가 **그대로** 쓴다
- 그리드를 바꿔도 화면 코드가 안 바뀐다 — 래퍼 하나만 고친다
- `MesColumn`이 tui-grid 기능을 다 못 덮으면 **래퍼에 옵션을 더한다.** 화면이 우회하지 않는다
