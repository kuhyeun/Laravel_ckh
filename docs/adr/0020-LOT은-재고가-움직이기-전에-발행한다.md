# ADR 0020. LOT은 재고가 움직이기 전에 발행한다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/ERD.md` §7, `docs/screens/20-기준정보.md`

## 배경

입고 자재에 라벨을 붙이려면 번호가 있어야 한다. 그런데 입고검사를 거치면
합격까지 며칠이 걸리고, 그동안 **물건은 이미 현장에 있다.**
출하도 같다 — 라벨을 붙이고 실어야 출하완료를 친다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 재고 반영 시점에 발행 | **라벨 붙일 번호가 없다.** 검사 대기 중 물건을 식별 못 한다 |
| 임시 번호 후 교체 | 붙인 라벨과 최종 번호가 다르다. 추적이 끊긴다 |
| **등록 시점에 발행** | 채택 |

## 결정

```
입고등록 ─▶ [LOT 발행 · 라벨] ─▶ 검사 ─▶ 입고완료 ─▶ ledger +
출하등록 ─▶ [LOT 발행 · 라벨] ─▶ 적재 ─▶ 출하완료 ─▶ ledger −
```

LOT 번호는 `lot_rule`의 **요소 조합**으로 만든다 —
`ITEM_CD` · `DATE` · `SEQ` · `PARTNER` · `LOT_NO` · `PLANT` · `LINE` · `SHIFT`.

- **날짜는 `YY` · `YYMM` · `YYMMDD` 중에 고르고, 그 단위가 순번 리셋 주기가 된다**
- **거래처는 입고 · 출하 · 외주에만** 넣는다. 재고 기반 지시는 납품처가 없어
  번호 길이가 들쭉날쭉해진다 (ADR 0012). 넣을지는 `NEVER` / `ALWAYS` / `ASK`
- 출하 LOT은 **쓸지 말지부터 고른다** — `NONE`(제품 LOT 그대로) / `AUTO` / `EXTERNAL`

## 결과

- **쓰이지 않은 LOT이 남는다.** 등록만 하고 취소하거나 전량 불합격일 때.
  지우지 않고 `LBL-02`에 미사용으로 둔다 — **번호를 재사용하지 않는다.**
  비는 번호가 생기는 것이 같은 번호가 두 물건을 가리키는 것보다 낫다
- `YY` + 순번 3자리는 **연 999건**이 상한이다. 규칙 저장 시 경고한다
