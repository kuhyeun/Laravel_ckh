# ADR 0022. 시리얼은 개체 식별자이고, 재고 단위를 바꾸지 않는다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/ERD.md` §10

## 배경

중요 제품은 낱개마다 번호가 붙는다. 기존 `barcode_label`은
*"동일한 바코드 번호로 발행 가능"*이라 **UNIQUE를 걸지 않는** LOT 라벨이다.
낱개 추적에는 정반대 성질이 필요하다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| `barcode_label` 재사용 | 중복을 허용하는 테이블은 **개체 식별자가 못 된다** |
| 재고를 낱개 단위로 | `stock_ledger`가 **100배**가 된다. 수불의 의미가 사라진다 |
| **별도 `serial` + 재고는 LOT 단위 유지** | 채택 |

## 결정

- `serial` 테이블. `(tenant_id, serial_no)`에 **UNIQUE를 건다**
- 켜는 것은 **품목**이다 — `item.serial_use`. 정책이 아니라 품목의 성질이다
- 발번은 **최종 생산 공정 실적이 확정될 때** 그 수량만큼. **불량은 발번하지 않는다**
- 상태 넷: `STOCK` · `SHIPPED` · `DEFECT` · `SCRAPPED`
- 번호는 `LOT번호 + 순번`이 기본형 — **시리얼만 보면 어느 LOT인지 안다**

## 결과

- 재고 모델이 안 바뀐다. 시리얼은 LOT 안의 **식별표**다
- **시리얼 개수와 LOT 재고가 어긋날 수 있다.** 어긋나면 **원장을 믿는다** —
  `TRC-03`이 둘을 나란히 보여 주고 차이 나는 LOT을 위로 올린다
- 수량이 큰 품목에 켜면 행이 그만큼 생긴다. 등록 화면에서 경고한다
