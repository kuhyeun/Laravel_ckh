# ADR 0011. 초 · 중 · 종 검사는 개별로 켜고, 켜진 것 중 마지막이 완료다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/ERD.md` §9

## 배경

초중종 검사를 하나의 검사 공정으로 묶고 *"종물이 끝나면 완료"*로 잡았다.
그런데 **초물과 종물만 하는 현장**이 있다. 중물을 안 하는데 종물을 기다리게 하거나,
반대로 중물만 하는 경우를 표현할 수 없다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 종물 고정 완료 | 종물을 안 하는 라우팅에서 공정이 안 닫힌다 |
| 검사 횟수(N)만 지정 | 어느 것이 초물인지 구분이 사라진다 |
| **셋을 개별 on/off** | 채택 |

## 결정

`routing_line.insp_first` · `insp_middle` · `insp_last` 세 컬럼.

- 최소 하나는 켜야 한다 — 셋 다 끄면 검사 공정을 둘 이유가 없다
- **완료 기준은 켜진 것 중 마지막**
- 꺼진 체크포인트는 **인쇄와 스캔에 나타나지 않는다**

## 결과

- 라우팅마다 검사 강도를 다르게 줄 수 있다
- 완료 판정 로직이 *"마지막 켜진 것"*을 계산해야 한다 — 고정 상수가 아니다
- 작업지시에 **복사**된다. 라우팅을 나중에 바꿔도 진행 중 지시는 그대로
