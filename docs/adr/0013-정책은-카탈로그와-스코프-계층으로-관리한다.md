# ADR 0013. 정책은 카탈로그와 스코프 계층으로 관리한다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/정책-설정-설계.md`

## 배경

업체마다 다른 것이 45가지다. 코드에 `if`로 박으면 업체 수만큼 분기가 늘고,
전부 화면 설정으로 열면 **잘못 만지면 데이터가 깨지는 것**까지 열리게 된다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 코드 분기 | 업체가 늘 때마다 코드가 는다 |
| 전부 업체 설정 | 계산식·바코드 중복 허용처럼 **되돌릴 수 없는 것**이 열린다 |
| **카탈로그 + 권한 + 스코프 계층** | 채택 |

## 결정

- `policy_def` 카탈로그에 **키 · 타입 · 기본값 · 설정 권한**을 정의한다
- `FEATURE` 12건은 전부 **시스템관리자 전용** (메뉴 자체를 켜고 끈다)
- `RULE` 33건 중 8건이 시스템관리자, 25건이 업체
- 값은 `policy_value`에 **스코프**(`TENANT` → `ENTITY`)로 저장하고, 좁은 것이 이긴다
- 입고검사는 예외 — **품목이 무검사면 거래처를 무시**한다(`EXEMPT_THEN_PRIORITY`)

## 결과

- 정책 하나가 **테스트 경로를 두 배**로 만든다. 45건이면 적지 않다 — 더 늘리지 않는다
- 기능 스위치를 껐다 켜도 **데이터는 남는다.** 스위치는 노출과 동작만 제어한다
- 화면이 유효값을 **어디서 왔는지와 함께** 보여 줘야 한다
