# ADR 0017. 화면은 페이지와 모달 둘 다로 열린다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/프로그램-스펙.md` §12.3, `docs/screens/01-공통컴포넌트.md`

## 배경

품목 등록은 메뉴에서도 열리고 수주등록 중에도 열려야 한다.
같은 폼을 두 벌 만들면 필드가 갈라지고, 한쪽만 고치는 사고가 난다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 페이지 전용 + 이동 | 수주 입력 중에 나갔다 오면 **쓰던 것이 날아간다** |
| 모달 전용 | 깊은 링크가 안 된다. 즐겨찾기·새 탭이 막힌다 |
| **본체를 감싸는 두 껍데기** | 채택 |

## 결정

```
pages/master/items/[id].vue   ─┐
                               ├─ ItemForm.vue   ← 라우터를 모른다
useItemModal()                ─┘
```

본체는 `saved` · `cancel` **이벤트만** 낸다.
닫기와 이동은 **감싼 쪽이** 정한다. 모달은 만든 것을 **돌려준다** —
수주등록에서 품목을 만들면 그 품목이 그대로 선택된다.

## 결과

- 폼 로직이 한 곳이다
- 본체에서 `router.push`를 쓰면 안 된다 — **규칙으로 지켜야 한다**
- 모달 껍데기는 바깥 클릭으로 닫히지 않는다. 입력 중 유실을 막는다
