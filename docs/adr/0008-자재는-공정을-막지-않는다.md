# ADR 0008. 자재는 공정을 막지 않는다

- 상태: 채택
- 날짜: 2026-09-02
- 관련: `docs/재고-수불-설계.md`

## 배경

자재가 없으면 공정을 시작 못 하게 막는 것이 데이터상 깔끔하다.
그러나 현장은 **먼저 깎고 나중에 자재를 정리**한다. 창고에서 빼오는 시점이
공정 시작 이후일 수 있고, 출고 처리를 안 한 자재를 그냥 쓰기도 한다.

## 검토한 대안

| 대안 | 문제 |
|---|---|
| 자재 부족이면 공정 시작 차단 | **현장이 시스템을 우회한다.** 나중에 몰아서 입력하면 이력이 거짓이 된다 |
| 출고 → 사용을 강제 순서로 | 창고 담당과 작업자가 다른 사람이다. 대기가 생긴다 |
| **막지 않고, 사용 시점에 정산한다** | 채택 |

## 결정

- 출고 · 공정 시작 · 사용처리는 **순서가 정해져 있지 않다**
- **자재투입 공정을 완료하는 순간** 그 줄의 자재가 사용처리된다
- 출고되지 않은 자재를 썼으면 **자동으로 출고 처리**한다
- 재고가 없으면 **음수 재고를 허용**하고 미결로 띄운다 (`INV-08`)
- 차감 방식은 **자동(선입선출) / 수동(바코딩·선택)** 중에 고른다

## 결과

- 현장이 시스템을 우회할 이유가 줄어든다
- **음수 재고가 정상적으로 생긴다.** 이것을 오류가 아니라 **처리해야 할 미결**로 다룬다
- 재고 정확도는 미결을 얼마나 빨리 닫느냐에 달린다 — 화면이 그것을 보여 줘야 한다
