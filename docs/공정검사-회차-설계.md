# 공정검사 회차 설계 ( 검사 공정 나눠 검사하기 )

> 작성일: 2026-11-23 · 상태: 확정 ( 11-23 사용자 확인 ) · 대상: 라우팅의 **검사 공정** ( 품질 모듈이 켜져 있을 때 ) — 초 · 중 · 종은 그대로

---

## 1. 목적

지금은 앞 공정이 모두 끝나야 검사를 **한 번에** 끝낸다.
→ 앞 공정 실적이 쌓이는 대로 **여러 번( 회차 ) 나눠 검사**하고, 합격분은 회차마다 바로 다음 공정 · 입고로 넘긴다.

---

## 2. 검사할 수 있는 수량

**검사 가능 = 앞 수량 공정의 누적 실적 − 이미 검사한 수량( 취소 제외 회차의 합격 + 불합격 )**

- 앞 공정이 진행 중이어도 실적이 있으면 검사할 수 있다
- 한 회차에 가능 수량보다 적게 검사해도 된다 ( 남은 것은 다음 회차 )

| 예 | 가공 실적 | 검사 가능 | 검사 |
|---|---|---|---|
| 한 번에 | 20 + 30 | 50 | 1회차 50 |
| 나눠서 | 20 | 20 | 1회차 20 |
|  | +30 | 30 | 2회차 30 |

---

## 3. 회차 한 번

- 입력 : 합격 + 불합격 = 이번 검사 수량 · 불량 내역 · 검사자 · 검사 일시 · 비고 · ( 성적서 켬 ) 측정값
- 기록 : 검사 기록 한 건( `inspection` PROCESS ) = 회차 하나 · 불량 · 성적서는 회차에 딸림
- 검사 공정 수량 = **취소 제외 회차의 합격 합계** → 다음 공정의 기준 수량
- 검사 공정 상태 : 첫 회차부터 「진행」

---

## 4. 실적별 LOT 지시 ( 공정 LOT 추적 )

- 회차마다 **아직 검사 안 한 가공 실적 LOT** 를 고르고 LOT 마다 검사 수량 · 불합격 수량 ( LOT 별 합격 = 검사 − 불합격 )

```
1회차   LOT            검사   불합격
        PDH-02_R001     20      1     → 합격 19
```

- 새 표 `inspection_lot` ( 회차 × LOT : 검사 수량 · 불합격 수량 )
- 불량이 **어느 LOT 에서 나왔는지** 남는다 ( 지금의 「마지막 LOT 부터 덜 입고」 없음 )
- 다음 공정의 투입 후보( 앞 공정 실적 LOT )는 **검사를 통과한 수량까지만**

---

## 5. 입고 ( 검사 공정이 마지막일 때 )

- 회차를 저장하면 그 회차의 **합격 수량을 바로 제품 입고** ( 실적별 LOT = LOT 마다 · 아니면 지시 LOT ) · 입고 창고는 회차 입력 때 고른다
- 줄 완료 때 따로 입고하지 않는다 ( 이미 회차마다 들어감 )

---

## 6. 검사 공정 완료

- **자동** : 앞 공정이 완료됐고 검사 가능 수량이 0 이 되면 자동 완료 ( 마지막 공정이면 줄도 완료 )
- **수동 [검사 완료]** : 남은 수량을 검사하지 않고 끝낼 때 — 생산 공정처럼 **미달 사유**
- **[완료 취소]** : 공정만 다시 「진행」 ( 회차는 그대로 )

---

## 7. 회차 취소

- 그 회차의 합격분이 검사 공정 수량에서 빠지고, 입고했으면 입고 되돌림( 역분개 ) · 불량은 취소 표시
- 막는 경우
  - 다음 공정 실적이 이미 그 합격분을 썼을 때 ( 다음 공정 실적이 줄어든 기준을 넘게 됨 )
  - 입고된 제품이 이미 출고 · 이동됐을 때
  - 검사 공정이 완료된 상태 ( 먼저 [완료 취소] )
- 취소한 수량은 다시 검사할 수 있게 된다

---

## 8. 화면

- **공정검사 창** : 위에 「가공 실적 50 · 검사 20 ( 합격 19 · 불합격 1 ) · **검사 가능 30**」 → [이번 회차] 입력 → 회차 이력( 회차별 [성적서] · [취소] ) → [검사 완료]
- **공정검사관리 목록** : 검사 가능 수량이 있으면 「검사대기」 · 열 = 회차 수 · 누적 합격 · 누적 불합격 · 검사 가능
- **공정실적** : 검사 공정 줄의 실적 = 누적 합격 · [검사] 단추 그대로

---

## 9. 기존 데이터

이미 완료된 검사( 한 번에 끝낸 것 )는 **1회차**로 본다 — 검사 기록 한 건 = 회차 하나 · 공정 수량 = 합격 · 입고는 줄 완료 때 이미 끝남. 데이터는 바꾸지 않는다.

---

## 10. 범위 밖

- 초 · 중 · 종 검사 ( 지금 그대로 )
- 품질 모듈이 꺼진 업체의 검사 공정 ( 「완료만」 공정 그대로 )
- 외주 품질검사

## 부록 · 결정 요약

| 결정 | 값 |
|---|---|
| 검사 가능 | 앞 공정 누적 실적 − 검사한 수량 · 앞 공정 진행 중에도 |
| 회차 | 검사 기록 한 건 · 검사 공정 수량 = 회차 합격 합 |
| 실적별 LOT | 회차마다 LOT 고르고 LOT 별 불합격 · `inspection_lot` |
| 입고 | 검사가 마지막 공정이면 회차마다 합격분 바로 입고 |
| 완료 | 앞 공정 완료 + 남은 검사 0 이면 자동 · 덜 하고 끝내면 미달 사유 |
| 취소 | 회차별 · 뒤에서 쓰였거나 입고분이 나갔으면 막음 |
| 기존 데이터 | 1회차로 봄 ( 변경 없음 ) |
