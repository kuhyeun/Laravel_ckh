# 구매 · 자재 — 화면정의

> 작성일: 2026-10-08 · 상태: **PUR-01 · 02 확정 · 구현 완료** ( §9 는 제안대로 — 사용자 판단 2026-10-08 )
> `PUR-01` 발주목록 · `PUR-02` 발주등록 · 수정. `PUR-03` 입고등록과 `INV-*` 재고는 **다음에 이 문서에 더합니다** ( 재고 3층 설계와 함께 ).

**수주( [30-수주.md](./30-수주.md) )와 같은 모양입니다** — 서버 페이징 목록 · ▸ 줄 트리 · 공통 검색바 · 머리 + 줄 모달 · 상태 4단계 · 삭제 / 취소 규칙 · 첨부 · 엑셀( 줄 단위 ).
아래에는 **발주가 다른 것만** 적습니다. 적지 않은 것은 수주와 같습니다.

## 0. 공통

### 0.1 수주와 다른 점

| | 수주 | 발주 |
|---|---|---|
| 뜻 | 고객사가 우리에게 주문 | **우리가 구매처에 주문** |
| 거래처 | 고객사 구분 | **구매처 구분**( `is_supplier = Y` ) · 사용 중 |
| 품목 | 제품 대분류 | **자재 대분류**( 원자재 · 원소재 ) — §9-3 |
| 단가 기본값 | `std_sale_price` 판매단가 | **`std_buy_price` 발주단가** |
| 줄 날짜 | 납품일 | **입고 예정일**( `due_date` ) |
| 진행 수량 | 생산 · 출하 | **입고 수량**( `received_qty` ) — 입고( PUR-03 )가 채운다 |
| 아래 단계 | 작업지시 · 출하 | **입고** — 입고된 줄은 품목 변경 · 삭제 불가, 수량은 입고량 아래로 못 줄임 |
| 번호 | `SO-YYMMDD-NNN` | **`PO-YYMMDD-NNN`** |
| 줄 자동 완료 | 출하 ≥ 수량 | **입고 ≥ 수량** ( 입고 모듈 때 ) |

### 0.2 테이블

ERD §8 의 `purchase_order` · `purchase_order_line` 을 수주와 같은 방식으로 만듭니다.

```
purchase_order        머리   purchase_order_idx PK · order_no · order_date · partner_idx( 구매처 )
                             order_name · status · total_amount · approval_status · remark · ext_* 7칸
purchase_order_line   줄     purchase_order_line_idx PK · purchase_order_idx FK · line_no · item_idx
                             qty · unit_price · amount · due_date( 입고 예정일 ) · received_qty · line_status · remark
```

- 줄 PK 단일 — 입고 줄이 발주 줄 하나를 가리킵니다
- 커스텀 컬럼 슬롯 **7칸을 머리에 처음부터** ( [커스텀-컬럼-설계](../커스텀-컬럼-설계.md) — 발주 7 )
- 수주의 `customer_po_no`( 고객 발주번호 )에 해당하는 칸은 없습니다 — **이 발주번호가 곧 구매처에 주는 번호**입니다
- 발주서 결재( `approval_status` )는 Phase 2 ( 전자결재 ) — 지금은 `NONE`

## PUR-01 발주목록

수주목록( SAL-01 )과 같습니다. 열만 다릅니다.

```
│ ☐ │ 발주번호        │ 발주일     │ 구매처   │ 발주명   │ 품목         │ 수량  │ 금액      │ 입고 예정일 │ 입고   │ 상태 │
│ ☐ │▾ PO-261008-001  │ 2026-10-08 │ 대한철강 │ 10월 1차 │ RM-BAR-20 외 1│ 1,500 │ 4,200,000 │ 2026-10-12 │ 0 / 2 │ 확정 │
│   │   └ 1  RM-BAR-20 환봉 Ø20     1,000 m ×  3,000 = 3,000,000   예정 2026-10-12   입고 0          │
│   │   └ 2  RM-PLT-05 판재 5t        500 EA × 2,400 = 1,200,000   예정 2026-10-15   입고 0          │
```

| | |
|---|---|
| 검색 기간 기준 | `발주일` / `입고 예정일` |
| 검색어 | 발주번호 · 발주명 · 품번 · 품명 |
| 거르기 | 구매처 · 상태( 기본 진행 중 ) |
| 입고 예정일 | 입고가 끝나지 않은 줄 중 **가장 이른 예정일**. 지났으면 붉게( 입고 지연 ) |
| 입고 | **입고 끝난 줄 수 / 전체 줄 수** — 줄에서는 입고 수량 |
