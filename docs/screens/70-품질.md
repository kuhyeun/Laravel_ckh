# 70. 품질 ( 6001 ~ 6004 )

> 입고검사( 6001 )는 [40-구매자재.md](40-구매자재.md) §12. 이 문서는 검사 공통 · 출고검사( 6003 ) · 공정검사( 6002 ) · 불량이력( 6004 ).
> 진행 순서 ( 2026-10-29 확정 — 제안대로 ) : **§1 공통 → §2 출고검사 → §3 공정검사 → §4 불량이력**

## 0. 정한 것 ( 2026-10-29 )

| # | 무엇 | 결정 |
|---|---|---|
| 1 | 불량 유형 | 코드관리 **`DEFECT_TYPE`** ( 치수 · 외관 · 기능 · 재질 · 기타 ) — 불합격이면 유형 필수, 기타면 상세 필수. 입고검사도 같은 방식 |
| 2 | 검사 취소 때 불량 기록 | 지우지 않고 **취소 표시**( `defect.is_canceled` ) — 불량이력에 취소분으로 남는다 ( 기본 조회에서는 뺀다 ) |
| 3 | 공정검사 불합격 수량 | **다음 공정 · 제품 입고에서 뺀다** ( 합격분만 넘어간다 ) |
| 4 | 초 · 중 · 종 | 켜진 검사마다 합격 / 불합격 기록, 모두 합격해야 완료. **종물 전 선행 진행 승인( ADR 0025 )은 다음 단계** |
| 5 | 측정값 입력 ( SHEET ) | 이번에도 제외 — 기준서는 참고로 보여 주기만 ( `quality.mode.*` = SIMPLE ) |

## 1. 공통 — 검사 기록 · 불량 기록

- 검사 한 번 = `inspection` 한 행 ( `insp_type` INCOMING · PROCESS · IFL_* · SHIPPING / `ref_type` + `ref_idx` = 검사한 대상 ) · `result` PASS / FAIL / PARTIAL · 합격 / 불합격 수량 · 검사자 · 일시
- 불합격분 = `defect` 한 행 ( `DefectService` ) — 칸 : 검사 종류 · 품목 · LOT · **거래처**( 입고 = 구매처, 출고 = 고객사 ) · **발생 공정**( 공정검사 ) · **출하 줄**( 출고검사 ) · 수량 · **유형** · 상세 · 일시 · 취소 표시
- 검사자 기본값 = 로그인 사용자 ( 바꾸면 대신 입력 — 입력한 사람은 따로 남는다 )

## 2. 6003 출고검사 [ 완료 ]

- 대상 = **출하대기 줄 중 검사 정책( `quality.shipping_inspection` — 품목 범위 )이 켜진 품목**. 결재를 쓰면( `feature.approval` + `shipment.approval` ) 승인된 출하만
  - 정책을 나중에 켜서 줄이 검사 없음( NONE )으로 저장돼 있어도 대상으로 본다 ( 출하 단계 판정과 같게 )
- 화면 `Quality/ShippingInspection` ( 메뉴 `/quality/shipping` )
  - 검색 : 출하 예정일 · 출하번호 · 품번 · 품명 · LOT · 상태( **검사할 것**( 기본 ) · 불합격 · 합격 · 전체 ) · 고객사
  - 목록 : 출하 줄 단위 — 출하 줄( `출하번호 - 줄` ) · 예정 · 고객사 · 품목 · LOT · 수량 · 검사 · 검사일시 · 검사자 · 불합격 사유 · 출하 상태 / 열 설정 · 엑셀
  - 행 → 검사 창
- 검사 창 `ShippingInspectionForm` — 출고검사 · **출하 창( 줄의 [검사] )** 두 곳에서 연다
  - 출하 · 고객사 · 수주 · 품목 · 수량 · 지정한 LOT / 출고 검사기준서 요약( 참고 )
  - **[합격] / [불합격]** → 불합격이면 불량 수량( 기본 = 출하 수량, ≤ 출하 수량 ) · 유형 · 상세 / 검사자 · 검사일시 · 비고
  - 판정 뒤 : 결과 + **[검사 취소]**( 출하 전만 — 다시 검사대기, 불량은 취소 표시 ) / 첨부( 성적서 — 출하 줄 `shipment_line` )
- 판정 결과 → 출하 줄 `inspect_status` · 검사자 · 일시 · 사유( 불합격 ) — 출하 단계가 그대로 따라간다 ( 불합격 있으면 "불합격", 모두 합격이면 "출하 가능" )
- 불합격 줄 : 출하 창에서 수량 · LOT 을 고쳐 저장하면 다시 검사대기 ( 이미 있던 동작 ). **재고는 건드리지 않는다** — 폐기할 것은 재고조정
- 권한 : 보기 = 출고검사 · 출하관리 · 출하이력 중 하나 / 판정 · 취소 = **출고검사 쓰기** ( 출하 창에서 열어도 같다 — 서버가 `can_write` 를 같이 준다 )
- API `quality.shipping.*` ( list · formData · show · complete · cancel ) — `ShippingInspectionService` · `ShippingInspectionController`

## 3. 6002 공정검사 [ 완료 ]

- 대상 = 품목 줄의 **검사 공정**( 공정관리 공정 유형 = 검사 ) — 라우팅에서 온다
- **수량 사슬** : 검사 공정도 기준에 든다 — 검사 완료 때 **공정 수량 = 합격 수량** → 뒤 공정의 기준( 넘으면 차단 ) · 마지막이면 제품 입고 = 합격분 ( 결정 3 )
  - 품질 모듈이 켜져 있으면 검사 공정은 **검사 창에서만** 완료 ( 공정실적의 [완료]는 막힌다 — E_OP_INSPECT ) / 꺼져 있으면 예전처럼 [완료] = 전부 합격
  - 지금까지 [완료]만 한 검사 공정은 마이그레이션( `2026_10_29_000005` )이 전부 합격으로 수량을 채웠다
- **일반 검사** : 앞 공정이 모두 끝난 뒤 → 합격 + 불합격 = 검사 수량( 앞 공정 수량 ) · 불합격이면 유형 필수 → [검사 완료]
- **초 · 중 · 종** ( 공정 = 초중종 검사 · 지시에서 켠 것만 ) : 단계마다 [판정 기록]( 합격 / 불합격 · 불량 수량( 0 이면 판정만 ) · 유형 · 상세 )
  - 초물 · 중물은 앞 공정이 시작되면, 종물은 앞 공정이 끝난 뒤
  - 단계마다 **마지막 판정이 합격**이어야 [검사 완료] — 합격 수량 = 검사 수량 − 단계 불량 합 ( 결정 4 · 선행 진행 승인은 다음 단계 )
  - 단계 기록은 공정 완료 전 하나씩 취소 ( 불량은 취소 표시 )
- **검사 취소** = 공정 완료 취소 ( 뒤 공정이 시작 전 — 종합 기록 · 불량 취소 표시, 수량 0 · 다시 대기 ) — 품목 줄이 완료됐으면 공정실적에서 줄 완료 취소 먼저
- 마지막 남은 공정이면 검사 완료 때 줄을 끝내고 남은 합격분을 제품 입고 → 창에서 창고를 고른다
- 화면 `Quality/ProcessInspection` ( 메뉴 6002 `/quality/process` ) — 검색 : 착수 예정 · 줄 번호 · 품번 · 품명 · LOT · 상태( **검사할 것**( 기본 ) · 검사 완료 · 전체 )
  - 목록 : 품목 줄 · 검사 공정 · 구분( 일반 / 초 · 종 … ) · 착수 예정 · 품목 · LOT · 검사 수량 · 합격 · 불합격 · 상태 · 검사일시 · 검사자 · 막힌 이유 / 열 설정 · 엑셀
- 검사 창 `ProcessInspectionForm` — 공정검사 · **공정실적( 검사 공정 행의 [검사] )** 두 곳 / 이력( 종합 · 단계, 취소 포함 )
- 권한 : 보기 · 판정 = 공정검사 · 공정실적 어느 쪽이든 / 검사 취소 = 공정검사 쓰기 또는 공정실적 삭제
- 불량 = 발생 공정( `work_order_op` ) · 품목 = 만드는 제품 · LOT = 지시 LOT
- API `quality.process.*` ( list · show · complete · stage · cancelStage · cancel ) — `ProcessInspectionService` · `ProcessInspectionController`
