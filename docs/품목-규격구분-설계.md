# 품목 규격 구분 설계 ( 품번 + 규격 = 품목 )

> 상태 : **완료 ( 11-04 ) — 1단계 품목 기준 · 2단계 자재 찾기 · 새로 등록 · 3단계 품목 표시에 규격 ( 브라우저 확인은 아직 · 제품에도 적용할지는 보류 )**
> 관련 : ERD §6 item · [재고-수불-설계.md](./재고-수불-설계.md) §2-1 ( LOT 규격 — 원소재 길이 ) · [대체자재-수주자재-설계.md](./대체자재-수주자재-설계.md)

## 1. 목적

자재는 품명 · 품번이 같아도 규격이 다르면 다른 물건이다 ( 예 : 환봉 SUS-BAR `Φ10×1000` · `Φ12×1000` / 판 `100x10` · `100x20` ).
→ **품번 + 규격** 조합을 품목 하나로 본다. 품목이 다르므로 LOT · 재고 · BOM · 발주 · 출고도 따로 간다 ( 지금 구조가 품목 단위라 그대로 따라온다 ).

## 2. 결정 ( 11-04 )

| # | 항목 | 결정 |
|---|---|---|
| 1 | 규격 값 | **글자**( `item.spec` 100자 — 지금 칸 ) · LOT 의 숫자 규격( `lot.spec_value` — 원소재 잘라 쓰는 길이 )은 그대로 따로 |
| 2 | 같은 규격으로 볼 기준 | 앞뒤 · 가운데 공백 무시 · 대소문자 무시 · `x` / `X` / `×` 같게 — `100x10` = `100 X 10` = `100×10` |
| 3 | 적용 범위 | **자재( MATERIAL )만** — 제품은 **보류**( 정할 때까지 지금처럼 품번만으로 유일 ) |
| 4 | 새 자재 등록 | 자재를 고르는 곳에서 품번 · 품명 · 규격으로 찾고, 없으면 **작은 등록 창**( 품번 · 품명 · 규격 채움 → 소분류 · 단위만 고름 ) |
| 5 | LOT 번호 | LOT 규칙에 **규격 요소** 추가 ( 같은 품번 · 다른 규격 LOT 을 번호로 구분 ) |

## 3. 데이터

- `item.spec_key` ( 새 칸 · NOT NULL · 기본 '' ) = 규격을 §2-2 규칙으로 정리한 값 — 저장할 때 모델이 채운다 ( `Item::specKey()` )
- 유일 키 : `item_code` 유일 → **`( item_code, spec_key )` 유일**
- 제품 ( 보류 동안 ) : 품번이 같은 다른 품목이 있으면 안 됨 ( 화면 검증 ) / 자재 : 품번 + 규격이 같은 자재 · 같은 품번의 제품이 있으면 안 됨

## 4. 단계

| 단계 | 내용 |
|---|---|
| **1. 품목 기준** | `spec_key` · 유일 키 · 저장 검증( 화면 · 엑셀 ) · 엑셀 일괄 등록의 같은 품목 찾기 = 품번 + 규격 · LOT 규칙 규격 요소 |
| **2. 자재 찾기 · 새로 등록** | 공통 자재 고르기( 품번 · 품명 · 규격 검색 · 없으면 작은 등록 창 ) — 품목 화면 주 자재 · BOM관리 · 대체 자재 · 수주 [자재] 창 |
| **3. 품목 표시에 규격** | 품목 선택지 · 표시에 규격을 붙인다 ( 같은 품번이 두 줄로 보이지 않게 — 수주 · 발주 · 입고 · 출하 · 작업지시 등 ) |

## 5. 규격 코드 ( 11-04 추가 )

- 코드관리에 **규격 그룹 `SPEC`** — 코드키 = 규격 비교 값( `Item::specKey` ) · 코드명 = 입력한 그대로. 같은 규격은 두 번 등록되지 않는다 ( 코드관리에서 넣어도 서버가 코드키를 정한다 )
- 품목 규격 칸 = **규격 고르기**( `SpecPicker` — 목록에서 찾기 · 낱말 · 공백 · 대소문자 · x/× 무시 ) — 품목 화면 · 새 자재 등록 창 · 제품도 같다
- **목록에 없는 규격도 넣을 수 있다** ( 막지 않음 ) → 품목 저장 · 엑셀 등록 · 새 자재 등록 때 **규격 코드에 자동 추가** ( `SpecCodeService::ensure` )
- **[+ 새 규격 추가]** : 품목관리 쓰기 권한이면 바로 규격 코드에 더하고 고른다 ( `config.item.quickSpec` )
- 품목에는 규격 글자를 그대로 저장한다 ( 코드를 바꾸거나 미사용으로 내려도 품목 규격은 그대로 )
