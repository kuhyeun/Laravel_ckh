# 검사성적서 설계

> 작성일: 2026-11-23 · 상태: 확정 ( 11-23 사용자 확인 )

---

## 1. 목적

지금은 성적서를 파일로 **첨부만** 한다. 업체가 **성적서를 MES 에서 만들어 관리**하기로 할 때만 검사기준서를 성적서 양식으로 쓴다.
검사자가 기준서 항목에 측정값을 넣고, 그 화면을 인쇄하면 그대로 **성적서**가 된다.

---

## 2. 시스템 설정 ( 검사 종류별 )

| 키 | 이름 | 기본 |
|---|---|---|
| `quality.report.incoming` | 입고검사 성적서 관리 | 끔 |
| `quality.report.process`  | 공정검사 성적서 관리 | 끔 |
| `quality.report.shipping` | 출하검사 성적서 관리 | 끔 |

- 지금 숨어 있는 `quality.mode.*` ( SIMPLE / SHEET ) 를 이 이름으로 바꾼다 ( 켬 = SHEET · 끔 = SIMPLE )
- **끔** : 지금처럼 판정 · 수량만. 검사 창의 [성적서] 탭 · 공정검사관리의 [검사기준서] 버튼이 안 보인다
- **켬** : 그 검사 창에 [성적서] 탭이 보이고, 측정값을 **모두 넣어야** 검사를 저장할 수 있다
- [첨부] 탭은 설정과 관계없이 그대로 ( 공급사 성적서 · 밀시트 같은 외부 문서 )
- 검사 기록 `inspection.mode` 에 그때의 방식( SIMPLE / SHEET )을 남긴다

---

## 3. 검사기준서 ( 성적서 양식 )

- 기준서 줄에 **시료 수**( `sample_count` · 기본 1 · 1 ~ 10 ) — 이 수만큼 측정값 칸
- **기본 기준서를 검사 종류별로** : 입고 기본 · 공정 기본 · 출하 기본
  - 기준서에 「기본으로 쓸 검사」 체크( 입고 · 공정 · 출하 ) — 한 종류에 기본은 하나 ( 다른 기준서를 켜면 넘어감 )
  - 기존 `is_default = Y` 인 기준서( 「공정검사」 )는 공정 기본으로
- 검사 창에서는 그 종류의 기본 기준서가 먼저 골라져 있고 다른 기준서로 바꿀 수 있다
- 기준서관리 메뉴는 설정과 관계없이 그대로 ( 미리 만들어 둘 수 있게 )

---

## 4. 측정 기록

새 표 `inspection_measure` — 검사 한 건 × 기준서 줄 하나 = 한 줄

| 칸 | 내용 |
|---|---|
| `inspection_idx` | 검사 |
| `seq` | 순서 |
| 항목명 · 성격 · 방법 · 규격 · 하한 · 상한 · 단위 · 판정 기준 | 저장 때 기준서 줄의 **복사본** |
| `sample_count` | 시료 수 |
| `measured` | 시료별 측정값 ( JSON 배열 — 정량 숫자 / 정성 OK · NG ) |
| `judge` | 그 줄 판정 OK / NG |

- 기준서를 나중에 고쳐도 지난 성적서는 그대로
- 판정
  - 정량 : 측정값이 하한 ~ 상한을 벗어나면 NG ( 한쪽만 있으면 그쪽만 )
  - 정성 : 시료마다 OK / NG 를 고른다
  - 줄 : 시료 하나라도 NG 면 NG
  - 종합 판정 **제안** : NG 줄이 있으면 「불합격」 — 합격 · 불합격 수량은 지금처럼 사람이 정한다 ( 일부 합격 )
  - 서버도 같은 계산으로 판정을 다시 매긴다 ( 화면 값을 믿지 않는다 )
- 검사를 취소하면 측정 기록도 같이 취소된 것으로 본다 ( 검사 기록에 딸림 )
- 공정검사의 초 · 중 · 종물은 검사 기록마다 성적서 하나

## 5. 검사 창 [성적서] 탭 ( 입고 · 공정 · 출하 공통 컴포넌트 )

```
기준서 [ 공정검사 ( 공정 기본 ) ▾ ]                                  [인쇄]
No 항목  방법    기준                시료1  시료2  시료3   판정
1  외경  캘리퍼  Φ20 ( 19.9 ~ 20.1 ) 20.02  19.98  20.15   NG
2  외관  육안    찍힘 없을 것        OK     OK     OK      OK
                                        종합 판정 제안 : 불합격
```

- 범위를 벗어난 값은 빨강
- 기준서를 바꾸면 입력한 값을 지울지 묻는다
- 저장된 검사를 다시 열면 그때 복사한 줄과 값 ( 기준서는 바꿀 수 없음 )
- 입고 · 출하 창의 「기준서 : 없음」 한 줄 요약( 품목 기준 조회 — 11-18 이후 깨져 있음 )은 이 탭으로 바꾼다

---

## 6. 인쇄 ( 검사성적서 )

- 문서 양식( 기준정보관리 )에 종류 **「검사성적서」( `INSPECTION_REPORT` )** 추가
- 머리 · 아래 항목 : 검사 종류 · 문서 번호( 입고번호 / 작업지시 · 공정 / 출하번호 ) · 품번 · 품명 · 규격 · LOT · 거래처( 구매처 / 고객사 ) · 검사 수량 · 합격 · 불합격 수량 · 종합 판정 · 검사 일시 · 검사자 · 기준서 이름 · 우리 회사 · 출력 정보
- 표 열 : No · 항목 · 성격 · 방법 · 규격 · 하한 · 상한 · 허용 범위 · 단위 · 판정 기준 · 기준( 합침 ) · **시료 1 ~ 시료 10** · **측정값( 합침 — 「20.02 / 19.98 / 20.15」 )** · **판정** · 빈 칸
- 양식이 없으면 고정 배치로 인쇄 ( 지금 다른 문서와 같음 )
- 인쇄는 저장된 검사 기록 기준 ( 저장 전에는 [인쇄] 막음 )

---

## 7. 범위

- 포함 : 입고검사 · 공정검사( 공정검사관리 + 공정실적 [검사] ) · 출하검사
- 제외 : 외주 품질검사( 외주관리 ) — 필요하면 같은 탭을 붙인다
- 제외 : 검사 수량에 따른 시료 수 자동( AQL ) — 시료 수는 기준서 줄에서 고정

## 부록 · 결정 요약

| 결정 | 값 |
|---|---|
| 설정 | 검사 종류별 3개 · 기본 끔 · 숨은 `quality.mode.*` 를 바꿔 씀 |
| 측정값 | 켜면 필수 · 시료 수는 기준서 줄마다( 1 ~ 10 ) |
| 기록 | `inspection_measure` — 기준서 줄 복사본 + 값 + 판정( 서버가 다시 계산 ) |
| 기본 기준서 | 검사 종류별 하나 |
| 첨부 | 그대로 ( 외부 성적서 ) |
| 인쇄 | 문서 양식 「검사성적서」 · 시료 1 ~ 10 열 |
| 범위 | 입고 · 공정 · 출하 ( 외주 제외 ) |
