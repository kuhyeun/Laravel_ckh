# 생산계획 설계

> 작성일 : 2026-11-05 · 상태 : **1차 구현 완료** ( 브라우저 확인 전 )
> 관련 : [라우팅-3단계-설계.md](./라우팅-3단계-설계.md) · [대체자재-수주자재-설계.md](./대체자재-수주자재-설계.md) · 화면 [50-생산](./screens/50-생산.md) · 작업내역 146

## 1. 흐름 — 생산계획은 선택

```
수주 줄 ──┬──────────────────────────────▶ 작업지시   ( 지금처럼 바로 )
          │
          └─▶ 생산계획 ( 선택 ) ──[작업지시]──▶ 작업지시   ( 계획에서 가져오기 )
               계획 하나 = 품목 하나 · 기간 · 수주 줄 여럿 ( 11-05 추가 )
               예) PP-001  P-100  11/10~11/12  150  ← SO-001 #1 A사 100 · SO-002 #2 B사 50
               수주 줄 하나를 여러 계획에 나눠 담아도 된다 ( 100 → 11/10 60 · 11/20 40 )
```

## 2. 결정 ( 11-05 사용자 확정 — 전부 제안대로 + 끌어 옮기기 1차 포함 )

| # | 항목 | 결정 |
|---|---|---|
| 1 | 공정 · 자재 | **수주 줄 것을 그대로** — 계획 화면의 [공정] · [자재] 는 그 수주 줄의 공정 · 자재를 같이 고친다 ( 사본을 한 단계 더 만들지 않는다 · 잠금 규칙 그대로 ) |
| 2 | 수주 없는 계획 | 지금은 **수주 기준만** |
| 3 | 계획 · 수주 양쪽에서 지시 | 둘 다 허용 · 수주 줄 기준 남은 지시 수량 규칙은 지금 그대로 · 계획은 "계획 대비 지시"만 따로 셈 |
| 4 | 달력 끌어 옮기기 | **1차 포함** ( 사용자 평이 좋았던 기능 ) — 기간 유지 |
| 5 | 4004 생산일정관리 | 그대로 ( 나중에 설비 · 공정별 일정 간트 ) |
| 6 | 계획에 수주 여럿 ( 11-05 추가 ) | **계획 하나에 수주 줄 여럿** — 품목이 같고 **공정 순서 · 자재 구성이 같은** 줄만 ( 작업지시와 같은 규칙 — 그대로 작업지시 줄 하나 ) · [공정] · [자재] 는 **담긴 줄 전부**에 같이 적용 |

## 3. 데이터

`production_plan` · `production_plan_source` ( 마이그레이션 `2026_11_05_000003` )

| 칸 | 설명 |
|---|---|
| `plan_no` | PP-YYMMDD-NNN ( 등록일 기준 ) |
| `item_idx` | 품목 ( 담긴 수주 줄의 품목 — 모두 같다 ) |
| `qty` | 계획 수량 ( 출처 수량 합 ) |
| `start_date` · `end_date` | 생산 시작일 · 완료 예정일 ( 달력 막대 ) |
| `status` | `PLANNED` · `CANCELED` — 화면 상태( 계획 · 지시 일부 · 지시 완료 · 취소 )는 지시 수량으로 계산 |

- **`production_plan_source`** : 계획 · 수주 줄 · 이 계획에 담은 수량 ( unique 계획 + 수주 줄 · 수주 줄은 restrict )
- `work_order.production_plan_idx` → `production_plan` ( FK · null on delete — 자리는 10-12 에 만들어 둠 )
- 지시된 수량 = 그 계획에서 만든 작업지시( 취소 제외 )의 지시 수량 합

## 4. 규칙

| | |
|---|---|
| 대상 수주 줄 | 확정 수주 · 진행 중 줄 ( 이미 담긴 줄은 그대로 ) · **품목 같음 · 공정 순서 · 자재 구성 같음**( 첫 줄 기준 ) |
| 계획 합 > 수주 수량 | 경고 ( `W_PLAN_OVER` ) · 완료 예정일 > 수주 납기 경고 |
| 작업지시가 생긴 계획 | 담긴 수주 줄 변경 불가( 수량만 ) · 지시 수량 아래로 못 줄임 · 삭제 불가 ( 지시를 먼저 취소 ) |
| 삭제 | 지시가 없으면 삭제 · 취소된 지시만 있으면 계획 **취소**로 남김 |
| 계획 → 작업지시 | 계획마다 줄 하나 · 수주 연결 = 그 계획에 담긴 수주 줄들( 줄마다 남은 몫 ) · 계획에 없는 수주 줄은 막음 · 남은 계획 수량보다 많으면 경고( `W_WO_OVER_PLAN` ) |
| [공정] · [자재] | 담긴 수주 줄 **전부**에 `SalesOrderService::saveLineSetup` ( 한 트랜잭션 — 하나라도 막히면 전부 되돌림 ) — 수주 저장과 같은 검사 · 작업지시가 생긴 줄이 있으면 잠김 · 품목 BOM 에 없는 자재는 품목 BOM 에도 등록 |

## 5. 화면 — 4001 생산계획관리 ( `/production/plan` · `Production/ProductionPlan` )

- **월 달력** ( 일요일 시작 · 그 달 1일이 든 주 ~ 마지막 날이 든 주 — 4 ~ 6주 ) : 계획 = 시작 ~ 완료 막대 · 상태 색 · 주마다 줄을 나눠 겹치지 않게
  - 막대를 **끌어 날짜 옮기기** ( 4px 넘게 움직이면 끌기 — 기간 유지 · 바로 옮겨 보이고 실패하면 되돌림 ) · 누르면 수정 · 빈 날짜 누르면 그 날로 등록
  - 막대 왼쪽 체크 → **[작업지시]** ( 남은 수량이 있는 계획만 · 착수 = 가장 이른 시작일 · 기한 = 가장 늦은 완료일 ) · [삭제]
- **목록** : 같은 기간 · 거르기를 표로
- 거르기 : 검색어( 계획번호 · 수주번호 · 고객 · 품번 · 품명 ) · 상태( 기본 지시 남음 )
- 등록 창 `ProductionPlanForm` : 시작일 · 완료 예정일 · 비고 · **담긴 수주 줄 표**( 줄마다 담을 수량 · 지시됨 ) · [+ 수주 줄 담기]( 계획 안 잡힌 수량 · 첫 줄과 공정 · 자재가 다르면 흐리게 + 이유 ) · [공정] · [자재]
- 달력 막대 · 목록 : 고객 · 수주는 "A사 외 1" 처럼 요약 · 막대에 마우스를 올리면 담긴 수주 줄 전부
- 작업지시 창 : 계획에서 온 줄에 "계획 PP-…" 표시

## 6. 나중

- 수주 없는 계획( 재고 생산 )

- 수주 진행현황에 계획 칸
