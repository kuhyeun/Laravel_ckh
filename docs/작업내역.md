|---|---|---|

LOT 채번은 **순번 카운터 테이블**( 규칙 × 리셋 구간 )과 `LotRule::render()` 로 만듭니다.
MVP 완료 기준 : 수주 1건이 입고 → 작업지시 → 스캔 실적 → 검사 → 출하까지 시스템 안에서 끝나고, 재고와 LOT 이력이 맞는 것.
