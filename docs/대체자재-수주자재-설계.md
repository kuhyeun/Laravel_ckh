# 대체 자재 · 수주 자재 설계

> 상태 : **완료 ( 11-04 ) — 1단계 BOM 대체 자재 · 2단계 수주 자재 · 3단계 작업지시 자재 · 4단계 자재 출고 ( 브라우저 확인은 아직 · 비교 화면은 나중 )**
> 관련 : [라우팅-3단계-설계.md](./라우팅-3단계-설계.md) ( 같은 방식 ) · [자재소요-계산-설계.md](./자재소요-계산-설계.md) · ERD §6 BOM · 화면 BAS BOM관리 · 수주관리 · 작업지시 · 자재출고

## 1. 목적

- 제품의 BOM 자재 줄마다 **대신 쓸 수 있는 자재( 대체 자재 )** 를 여러 개 등록하고, 자재 출고 때 주 자재 대신( 또는 섞어서 ) 낼 수 있게 한다.
- 수주마다 자재 구성이 달라질 수 있으므로, 공정처럼 **수주 줄에서 그 수주의 자재를 설정**한다.

```
제품 P  ( BOM V1 )
 ├ 자재 줄 1 : 원자재 A   소요 2
 │    ├ 대체 : A-2        소요 2.2
 │    └ 대체 : A-3        소요 4
 ├ 자재 줄 2 : 부품 B     소요 1
 │    └ 대체 : B-2        소요 1
 └ 자재 줄 3 : 부품 C     소요 3     ( 대체 없음 )
```

## 2. 결정 사항 ( 11-04 사용자 확정 )

| # | 항목 | 결정 |
|---|---|---|
| 1 | 대체 자재 등록 | **BOM관리**에서 자재 줄마다 · 개수 제한 없음 |
| 2 | 수주에서 | 줄에 품목을 고르면 **[자재]** 창( 공정 창처럼 )에서 그 수주의 자재 설정 — 자재 줄 추가 · 삭제 · 소요량 · 투입 공정 · 대체 자재 추가 · 삭제 · 소요량 전부 |
| 3 | 소요량 | **대체 자재마다 따로** ( 소요 · 계산식 · 기능형 값 ) |
| 4 | 출고 | 한 자재 줄을 **주 자재 일부 + 대체 자재 일부로 섞어서** 채울 수 있다 |
| 5 | 출고 후보 자동 채움 | **주 자재만** — 대체 자재는 사람이 직접 고를 때만 ( 안전 ) |
| 6 | 재고 부족 판단 · 발주 | **지금 그대로** ( 주 자재 기준 — 대체 자재 재고는 가용으로 치지 않음 ) |
| 7 | 수주 자재 잠금 | 그 수주 줄로 **작업지시가 생기면 잠김** ( 공정과 같은 규칙 · 취소하면 풀림 ) |
| 8 | 이력 · 비교 | 수주 자재 **변경 이력만** 남긴다 · 비교 화면은 나중에 |
| 9 | 수주 → 품목 BOM ( 11-04 추가 ) | 수주에서 고른 자재 중 **품목 BOM 에 없는 것은 품목 BOM 에도 등록** — 없으면 BOM 생성( 주 자재 ) · 있으면 대체 자재 · 줄이 둘 이상이면 어느 줄의 대체인지( 또는 새 자재 줄 ) 고름 · **수주 쓰기 권한**으로 · 대체만 더하면 승인 유지 · 자재 줄이 늘면 승인 해제 ( §8 ) |

## 3. 3단계 구조 ( 공정 라우팅과 같은 방식 )

| 단계 | 무엇 | 고치는 곳 | 목록 노출 |
|---|---|---|---|
| ① | **품목 BOM** ( 버전 · 활성 · 승인 — 지금 그대로 ) + 대체 자재 | BOM관리 | 보임 |
| ② | **수주 줄 자재** = 수주 저장 때 ① 활성 BOM 복사 | 수주 줄 [자재] | BOM관리 목록에 안 보임 |
| ③ | **작업지시 자재** = 지시 저장 때 복사 ( 수주에서 온 지시 = ② · 재고 · 수동 = ① ) | ( 지금처럼 보기만 ) | — |

## 4. 데이터 구조

### 4.1 bom ( 칸 추가 ) — ② 를 같은 표에

| 칸 | 설명 |
|---|---|
| `owner_type` | `ITEM`( ① 기본 ) · `ORDER_LINE`( ② ) |
| `sales_order_line_idx` | ② 의 수주 줄 · unique · 줄을 지우면 같이 ( cascade ) |
| `base_bom_idx` | 복사해 온 원본 ( ② ← ① ) |

- ② 는 `item_idx` = 그 제품 · `version` = `SO-{줄 IDX}` · `is_active` = N ( 활성 BOM 찾기에 걸리지 않는다 )
- **스코프** `Bom::itemBoms()` = `owner_type = ITEM` — BOM관리 목록 · 버전 · 순환 검사 · 품목 화면 주 자재가 쓴다

### 4.2 bom_line_substitute ( 새 표 ) — 자재 줄의 대체 자재

| 칸 | 설명 |
|---|---|
| `bom_line_substitute_idx` | PK |
| `bom_line_idx` | 주 자재 줄 ( cascade ) |
| `seq` | 순서 ( 우선순위 · 표시 ) |
| `child_item_idx` | 대체 자재 품목 |
| `qty` · `calc_code` · `ext_n01` | **대체 자재 자기 소요** ( 계산식 · 기능형 값 — 주 자재와 같은 칸 ) |
| `remark` | 비고 |

- ① · ② 둘 다 이 표를 쓴다 ( 줄이 ① 줄이면 ① 의 대체, ② 줄이면 ② 의 대체 )
- BOM 버전 복사 · ② 복사 때 대체 자재도 함께

### 4.3 bom_line ( 칸 추가 )

| 칸 | 설명 |
|---|---|
| `source_bom_line_idx` | 복사해 온 원본 줄 ( ② ← ① ) — 이력 비교용 · FK 없음 |

- ② 줄의 **투입 지점**( `routing_line_idx` ) = 그 수주 줄의 **수주 공정( 라우팅 ③ ) 줄** ( ① 줄은 지금처럼 품목 공정 줄 )
  - 복사할 때 ① 줄의 투입 지점( 품목 공정 줄 ) → 그 줄을 원본으로 둔 수주 공정 줄로 바꾼다 · 없으면 NULL( 첫 수량 공정 ) + 경고
  - 수주 공정에서 그 줄을 지우면 FK 가 NULL 로 ( 지금 BOM 과 같음 )

### 4.4 work_order_material ( 칸 추가 ) — 대체 자재도 같은 표의 행으로

| 칸 | 설명 |
|---|---|
| `substitute_of_idx` | 대체 자재 행이면 **주 자재 행 IDX** ( 주 자재 행은 NULL ) |
| `bom_line_substitute_idx` | 복사해 온 대체 자재 ( 참고 ) |

- 대체 자재 행도 자기 `qty_per` · `calc_code` · `ext_n01` · `required_qty` · `issued_qty` 를 가진다 → **출고 · 보유 · 사용처리 · 반납 기계를 그대로 쓴다** ( 출고 줄이 그 행을 가리킴 )
- 투입 공정( `work_order_op_idx` )은 주 자재 행과 같다
- 주 자재 기준 계산( 부족 판단 · 발주 · 진행 요약 )은 `substitute_of_idx IS NULL` 행만

### 4.5 bom_change_log ( 새 표 ) — 수주 자재 변경 이력

- 칸 : scope( `ORDER_LINE` ) · ref_idx( 수주 줄 ) · bom_idx · action( `CREATE` · `RELOAD` · `ADD` · `REMOVE` · `UPDATE` · `SUB_ADD` · `SUB_REMOVE` · `SUB_UPDATE` ) · child_item_idx · before_json · after_json · 누가 · 언제
- CREATE · RELOAD 는 자재 구성 통째, 나머지는 줄 하나 ( 공정 이력과 같은 모양 )
- 비교 화면은 나중 ( 이 이력과 ② · ③ 으로 그린다 )

## 5. 흐름

### 5.1 BOM관리 ( ① )

- 자재 줄마다 **[대체 N]** → 펼쳐서 대체 자재 줄 추가 · 삭제 · 순서 · 소요 · 계산식
- 검증 : 대체 자재 ≠ 주 자재 · 같은 줄에 같은 대체 자재 두 번 금지 · 제품 자신 금지( 순환 )
- 품목 화면 "주 자재"( 자재 1개 바로가기 ) : 이미 주 자재가 있는데 다른 자재를 고르면 **[교체] / [대체 자재로 추가]** 를 묻는다

### 5.2 수주 ( ② )

- 줄에 품목을 고르면 ① 활성 BOM 을 ② 초안으로 → 줄의 **[자재 N]** 버튼( "수정됨" · "잠김" 표시 )
- 자재 창 : 자재 줄 표 + 줄마다 대체 자재 · [품목 BOM 에서 다시 불러오기] · [적용]( 수주 저장 때 반영 )
- 투입 공정 선택지 = 그 줄의 **수주 공정** ( 공정 창에서 고친 결과 — 저장 전이면 화면의 공정 )
  - 화면은 투입 공정을 **수주 공정의 순서( routing_seq )** 로 보낸다 → 서버가 공정을 먼저 저장하고 그 순서의 줄로 잇는다 ( 새 공정 줄은 저장 전 IDX 가 없으므로 )
- 저장 : 줄마다 ② 를 **항상** 만든다 ( 활성 BOM 이 없으면 빈 ② ) · 이력
- 잠금 : 그 줄로 작업지시가 생기면 자재 변경 422 · 품목을 바꾸면( 잠기기 전 ) 새 품목 BOM 으로 다시 ( RELOAD )
- 이관 : 기존 수주 줄마다 ② 생성

### 5.3 작업지시 ( ③ )

- 수주 줄을 담은 지시 : ② 복사 ( 대체 자재 → `substitute_of_idx` 행 ) / 재고 · 수동 : ① 활성 BOM
- **여러 수주 줄을 한 지시에** : 공정 순서에 더해 **자재 구성( 자재 · 소요 · 대체 )이 같은 줄끼리만** — 다르면 "따로 지시하세요"
- 자재 탭( 보기 ) : 주 자재 아래에 대체 자재를 들여 보여 준다

### 5.4 자재 출고

- 출고 계획 : 주 자재 행은 지금처럼 후보 LOT 자동 채움 · **대체 자재 행은 후보만 보이고 비워 둔다**( 사람이 고른다 )
- 출고 : 대체 자재 행에 낸 수량은 그 행의 `issued_qty` 로
- **채운 정도( 주 자재 기준 )** = 주 자재 출고 + Σ ( 대체 출고 × 주 소요 ÷ 대체 소요 ) — 예: 주 소요 2 · 대체 소요 4 → 대체 2 개 = 주 1 개분
  - 화면의 "남은 소요"는 이것으로 · 주 자재 후보 자동 채움도 남은 만큼만
- 사용처리( 투입 공정 시작 ) · 반납 : 행 단위 그대로 ( 대체 자재 행도 같은 규칙 )
- 부족 판단 · 발주 : 주 자재 행만 ( 지금 그대로 )

## 8. 수주에서 고른 자재 → 품목 BOM ( 11-04 추가 )

수주 [자재] 창에서 넣은 자재 중 **품목 BOM( ① 활성 )에 없는 자재**는 수주를 저장할 때 품목 BOM 에도 등록한다 ( `BomService::absorbIntoItemBom` — 수주 사본 맞추기 전에 ).
다음 수주에서 같은 품목을 고르면 그 자재가 처음 값으로 나온다.

| 품목 BOM | 수주 [자재] 창에서 | 품목 BOM 에 |
|---|---|---|
| 없음 | 자재 줄들 | **BOM 생성( 활성 · V{n} )** — 고른 줄 그대로 ( 첫 줄 = 주 자재 · 대체 포함 ) |
| 있음 | 원래 줄( `source_bom_line_idx` )의 자재를 바꿈 | 그 줄의 **대체 자재** |
| 줄 하나 | 새 줄 추가 | 주 자재 줄의 **대체 자재** |
| 줄 둘 이상 | 새 줄 추가 | 줄 아래에서 고름 ( `item_bom_target` ) : **어느 줄의 대체 자재** / **새 자재 줄** — 기본은 첫 줄의 대체 |
| 있음 | 대체 자재 추가 | 그 주 자재가 들어간( 들어갈 ) 줄의 대체 자재 |
| 있음 | 이미 있는 자재 · 소요 변경 · 자재 삭제 | **반영 안 함** ( 품목 BOM 을 줄이거나 바꾸는 것은 BOM관리에서 ) |

- **권한** : 수주 쓰기 권한이면 된다 ( BOM관리를 안 쓰는 업체도 수주에서 쌓을 수 있게 )
- **승인** : 대체 자재만 더하면 승인 그대로 · 자재 줄이 늘면( 구성 변경 ) 승인 해제
- **새 자재 줄의 투입 지점** : 수주 공정 줄의 원본( `source_routing_line_idx` )이 그 품목의 품목 라우팅 줄이면 그 줄 · 아니면 비움
- **이력** : `bom_change_log.scope = ITEM` · `ref_idx` = 품목 IDX · `after_json.from` = 수주 번호 ( CREATE · ADD · SUB_ADD )
- 품목 등록 창의 주 자재 칸은 그대로 ( 바꾸면 주 자재 교체 · [대체 자재로 추가] 선택 유지 )
