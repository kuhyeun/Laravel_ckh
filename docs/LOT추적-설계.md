# LOT 추적 ( LOT 관리 · 7006 ) — 설계

> 작성 2026-11-05 · 상태 **1차 구현 ( 11-09 )** — `LotTraceController` · `Pages/Shipment/LotTrace.vue` ( 작업내역 191 )
> 메뉴 : 출하관리 > LOT 관리 ( 7006 — 지금 "LOT 관리 ( 미개발 )" 자리 그대로 )

## 1. 목적

사용자가 **어떤 자재가 투입되어 LOT 이 어떻게 흘러갔는지** 본다. 두 가지 방식 ( 사용자 결정 11-05 ) :

| 탭 | 시작점 ( 검색 ) | 흐름 |
|---|---|---|
| **정추적** — 자재 → 출하 | 자재 LOT · 공급처 LOT · 입고 번호 · 자재 품번 | 입고 → 자재 LOT → 투입한 작업지시 → 제품 LOT → ( 반제품이면 다음 작업지시 → 제품 LOT … ) → 출하 → 고객사 |
| **역추적** — 제품 → 자재 | 제품 LOT · 출하번호 · 고객 PO · 작업지시번호 · 제품 품번 | 출하 **또는 출하 전 완성 제품 LOT** → 작업지시 → 투입 자재 LOT ( 반제품 LOT 이면 그 작업지시로 더 거슬러 ) → 입고 → 공급처 |

조회 전용. 클레임은 표시하지 않는다 ( 클레임관리 7004 에서 본다 ).

## 3. 연결 데이터 ( 지금 있는 것 — 새 기록 없이 만든다 )

```
공급처 ─ 입고 줄( stock_txn_line · IN_PURCHASE ) ─▶ 자재 LOT( lot.source = PURCHASE )
   ─ 출고 · 사용 · 반납( wo_stock : 지시 × 품목 × LOT ) ─▶ 작업지시( work_order )
   ─ 1 : 1 ( work_order.lot_idx ) ─▶ 제품 LOT( lot.source = PRODUCTION )
        ├─ 다시 자재로 출고되면 ( wo_stock.lot_idx = 이 제품 LOT ) → 다음 작업지시 … ( 다단계 )
        └─ 출하 줄 · 피킹( shipment_line / shipment_pick : LOT ) ─▶ 고객사
```

| 연결 | 근거 |
|---|---|
| 자재 LOT → 작업지시 | `wo_stock` ( issued · consumed · returned ) |
| 작업지시 → 제품 LOT | `work_order.lot_idx` ( 지시 하나 = 제품 LOT 하나 ) |
| 제품 LOT → 다음 작업지시 ( 반제품 ) | `wo_stock.lot_idx` 가 PRODUCTION LOT 인 줄 |
| 제품 LOT → 출하 | 출하 피킹 / 출하 줄의 LOT |
| LOT → 공급처 · 입고 | `lot.partner_idx` · 입고 원장 줄 |
| LOT 하나의 이력 | 재고 원장 ( 입고 · 출고 · 이동 · 조정 · 반납 · 생산 입고 · 출하 ) |
| 공정 불량 | `defect` ( insp_type PROCESS · SUBCON — work_order_op_idx → 작업지시 ) |

- 줄 종류 : 입고 · 자재 LOT · 작업지시 · 제품 LOT · 출하 · 재고( 남은 수량 )
- 수량 : 그 연결의 수량 ( 출고 · 사용 · 반납 / 생산 / 출하 ) — 단위 같이
- 제품 LOT 줄에서 **[역추적으로 보기]** · 자재 LOT 줄에서 **[정추적으로 보기]** — 탭을 바꿔 그 LOT 부터 다시
- 엑셀 : 펼친 트리 그대로 ( 들여쓰기 = 단계 열 )

## 5. 서버 ( 착수 때 )

- `LotTraceController` : `search`( 시작점 → LOT 목록 ) · `forward( lot_idx )` · `backward( lot_idx | shipment_line_idx )` · `history( lot_idx )` · `ops( work_order_idx )`
- **한 단계씩** 돌려준다 ( 펼칠 때 다음 단계 요청 ) — 다단계여도 무겁지 않게 · 같은 LOT 이 다시 나오면( 순환 ) 멈춘다
- 권한 : `Shipment/LotTrace` can_read

## 6. 한계 ( 지금 구조 )

- 자재 LOT ↔ 제품 LOT 은 **작업지시 단위**로 잇는다 — 지시에 자재 LOT 이 둘이면 "이 제품 LOT 에 둘 다 들어갔다"까지 ( 개당 매칭 없음 )
- 외주 · 재공은 LOT 이 없다 → [공정] 탭에서 지시 단위로 ( 외주처 · 출고 / 입고 수량 )
- LOT 기능( `feature.lot` )이 꺼진 업체는 LOT 이 0 → 이 메뉴는 숨기거나 "LOT 미사용" 안내
- 분할 생산 · LOT 쪼개기 / 합치기는 아직 없음 ( 생기면 연결 종류를 더한다 )
