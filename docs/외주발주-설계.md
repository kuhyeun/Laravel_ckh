# 외주 발주 설계

> 작성일: 2026-11-23 · 상태: 확정 ( 11-23 사용자 확인 )

---

## 1. 개념

- 외주 발주 = **외주 출고 앞의 선택 단계** — 외주처에 「이 작업지시의 이 외주 공정을 몇 개 · 얼마에 · 언제까지」 맡긴다는 기록
- **발주가 없어도 모든 흐름은 지금과 똑같다** ( 외주 출고 메뉴에서 바로 출고 )
- 확정 단계 없음 — 저장하면 발주를 낸 것

---

## 2. 메뉴

외주관리 > **외주 발주** ( 새 메뉴 · 외주 출고 위 )

- 목록 : 발주번호( `SCO-YYMMDD-NNN` ) · 외주처 · 발주일 · 납기 · 줄 수 · 발주 / 출고 / 입고 수량 · 상태
- 상태( 자동 ) : **발주**( 출고 전 ) → **진행**( 일부 출고 · 입고 ) → **완료**( 발주 수량만큼 입고 ) / **취소**

---

## 3. 발주서 ( 머리 + 줄 )

- 머리 : 외주처( 외주처 구분 거래처 ) · 발주일 · 납기 · 담당 · 비고
- 줄 : 작업지시의 외주 공정 하나 = 한 줄
  - 후보 : 대기 · 진행 중 작업지시의 끝나지 않은 외주 공정
  - **발주 수량 : 자유 입력** — 앞 공정 생산 수량보다 많으면 「앞 공정 생산 20 — 발주 30」 **안내만**
  - **단가** · 금액( = 수량 × 단가 ) · 줄 납기
  - 한 발주서에 같은 외주처의 여러 작업지시 공정
- 고치기 : 출고 전 줄은 자유 · 출고된 줄은 지울 수 없음 · 취소는 출고가 없을 때만
- [인쇄] : 문서 양식에 「외주 발주서」 종류

---

## 4. 발주서에서 바로 출고

- 발주서 줄마다 [출고] → 기존 외주 출고 창( 외주처 · 공정 · **단가 = 발주서 단가** 채움 )
- **출고 가능 = 앞 공정 생산 − 이미 출고** ( 지금 규칙 그대로 — **막는다** )
- 발주 남은 수량보다 많이 출고하면 **안내만** ( 막지 않음 )
- 금액 = 출고 수량 × 발주 단가
- 출고 기록에 발주 줄( `subcon_issue.subcon_order_line_idx` ) → 입고 · 검사는 기존 그대로 · 발주 줄의 출고 · 입고 수량이 쌓인다
- 외주 출고 메뉴에서 직접 출고( 발주 없이 )는 지금처럼 금액 = 총액

---

## 5. 자재 출고 — 외주 건에 자재 보내기

자재관리 > 출고관리에 **[외주] 탭**

- 목록 : 외주 발주 줄 / 발주 없이 한 외주 출고 건 — 외주처 · 작업지시 · 외주 공정 · 수량
- 고르면 : 그 외주 공정에 붙은 자재( 투입 공정 = 외주 공정 )가 **있으면 먼저 보여 주고**, **없어도 아무 자재나 골라서 출고** ( 사급 자재 등 )
- **수량은 직접 입력** ( 소요 계산 없음 )
- 출고 = 지금 자재 출고와 같은 기계 — 창고 → 작업지시 보유( ISSUE_WO ) · LOT 고르기 · 사용처리 시점 규칙 그대로
  - BOM 에 없는 자재는 그 지시의 BOM 외 자재 줄( 투입 공정 = 외주 공정 )로 붙는다
  - 출고 기록에 **어느 외주 건으로 나갔는지**( 외주처 ) 남는다
- 취소 · 반납 : 지금 자재 출고와 같다

---

## 6. DB

| 표 | 내용 |
|---|---|
| `subcon_order` ( 새 ) | 발주번호 · 외주처 · 발주일 · 납기 · 담당 · 비고 · 상태 |
| `subcon_order_line` ( 새 ) | 발주 · 작업지시 · 외주 공정 · 수량 · 단가 · 금액 · 줄 납기 |
| `subcon_issue` ( 칸 ) | `subcon_order_line_idx` ( 없으면 발주 없이 출고 ) |
| 자재 출고 ( 칸 ) | 외주 건 ( `subcon_order_line_idx` / `subcon_issue_idx` ) |

출고 · 입고 수량은 기록에서 계산 ( 따로 저장하지 않음 )

---

## 7. 범위 밖

- 외주 정산( 외주처별 월 금액 집계 ) — 발주 · 출고 금액이 남으니 나중에

## 부록 · 결정 요약

| 결정 | 값 |
|---|---|
| 발주 | 출고 앞의 선택 단계 · 확정 없음 · 없어도 지금 흐름 그대로 |
| 발주 수량 | 자유 · 앞 공정 생산보다 많으면 안내만 |
| 외주 출고 | 앞 공정 생산 − 이미 출고까지( 막음 ) · 발주 남은 수량 초과는 안내만 · 단가 = 발주서 |
| 자재 출고 | [외주] 탭 · 외주 공정 자재 먼저 · 아무 자재나 · 수량 직접 · 외주 건 기록 |
| 인쇄 | 문서 양식 「외주 발주서」 |
