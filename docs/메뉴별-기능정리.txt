[ 공통 ]  모든 화면에서 쓰는 기능
--------------------------------------------------------------------------------
  - 권한       : 메뉴별 읽기 / 쓰기 / 삭제. 권한 없으면 사이드바 · URL · API 모두 막힘
  - 그리드     : 서버 페이징 · 정렬 · 오른쪽 클릭 복사 · 체크 선택
  - 엑셀 내보내기 : 그리드 그대로 또는 양식 파일 ( 업체별 양식 덮어쓰기 가능 )
  - 엑셀 일괄 등록 : 양식 받기 → 업로드 → 검증 → 전부 성공일 때만 반영 · 결과 목록
                     ( 품목 · 거래처만 )
  - 첨부파일   : 구분( 도면 · 성적서 · 밀시트 · 기타 ) · 파일당 50MB
  - 공통 검색바 : 기간 기준 선택 · 오늘 / 이번 주 / 이번 달 · 검색어
  - 세션 만료  : 만료 5분 전 안내 배너 + [연장] · 만료 시 로그인 이동


================================================================================
 1. 설정 ( 관리자 메뉴 )
================================================================================

0001 시스템 설정 [완료]
  - 정책 카탈로그로 화면 구성 · 관리자 설정 / 시스템 설정 두 구역
  - 시스템 계정 : 전부 보고 수정 / 관리자 : 관리자 설정 구역만
  - 기본값 표시 · 기본값으로 되돌리기 · 선행 설정 연동( 꺼지면 하위 설정 숨김 ) · 변경 이력
  - 기능 스위치 ( 창고 · BOM · LOT · 시리얼 ) 를 끄면 해당 메뉴가 사이드바 · URL · API 에서 빠짐
  → 연결 : 창고관리 · BOM관리 · LOT규칙관리 ( 기능 스위치 )
           품목관리 · 거래처관리 ( 정책 덮어쓰기 )

0002 메뉴관리 [완료]  ※ 시스템 계정 전용
  - 메뉴 등록 / 수정 / 삭제 ( 하위 메뉴가 있으면 삭제 막음 )
  - 메뉴 코드 · URL 경로 중복 검사 · 상위 메뉴 코드 변경 시 하위 메뉴 함께 변경
  - 레벨별 권한( 노출 · 쓰기 · 삭제 ) · 정렬. 레벨 0( 시스템 ) 은 항상 전부 허용
  - URL 경로는 브라우저 주소만 바뀜 ( 데이터 API 주소는 코드에 고정 )
  → 연결 : 사용자권한관리 ( 레벨 1 권한은 여기서, 일반 사용자 권한은 사용자권한관리에서 )

0003 사용자관리 [완료]
  - 사용자 등록 / 수정 / 삭제 · 레벨 지정 ( 자기보다 높은 레벨은 수정 불가 )
  - 엑셀 내보내기
  → 연결 : 사용자권한관리 ( 권한 템플릿 · 개인 권한 )

0004 사용자권한관리 [완료]
  - 일반 사용자( 레벨 2 이상 ) 의 메뉴 권한 : 권한 템플릿 연결 + 개인별 덮어쓰기
  - 권한 템플릿 미리보기 · 템플릿 수정 시 연결된 사용자 전원 반영
  → 연결 : 사용자관리 · 메뉴관리

0005 코드관리 [완료]
  - 공통 코드 그룹 / 코드 등록 · 수정 · 삭제 ( 관리자는 삭제 불가 )
  → 연결 : 첨부 구분( ATTACH_TYPE ) · 재고조정 사유( ADJUST_REASON ) 등 여러 화면의 선택 항목

 2. 기준정보관리
================================================================================

1001 품목관리 [완료]
  - 품목 등록 / 수정 / 미사용 처리 ( 지우지 않고 내림 )
  - 탭 1 기본 · 탭 2 재고 · 발주( 안전재고 · 발주주기 · 최소수량 · 배수 ) · 탭 3 단가( 3종 )
  - 탭 4 추가정보 : 입고검사 · 출하검사 · 차감 위치 정책 덮어쓰기 · 리드타임 · 1개 생산 표준시간
  - 시리얼 사용 여부 · 커스텀 컬럼 예비 칸( 텍스트 5 · 숫자 3 · 날짜 2 )
  - 첨부 탭 · 엑셀 내보내기 · 엑셀 일괄 등록
  → 연결 : 공정라우팅관리 ( 기본 라우팅 지정 → 표준시간 자동 계산 · 제품만 )
           BOM관리 ( 주 자재 지정 시 1줄 BOM 자동 생성 · 제품만 )
           제조리드타임관리 · 검사기준서관리 ( 품목별 )
           수주 · 발주 · 입고 · 작업지시 ( 품목 선택, 판매단가 · 발주단가 기본값 )

1002 거래처관리 [완료]
  - 거래처 등록 / 수정 / 미사용 · 구분( 고객사 · 구매처 · 외주처 )
  - 담당자 N ( 구분 · 소속 출고지 ) · 출고지 N
  - 입고검사 정책 덮어쓰기 ( 구매처 · 외주처만 )
  - 첨부 탭 · 엑셀 내보내기 · 엑셀 일괄 등록
  → 연결 : 수주관리( 고객사 ) · 발주서관리 / 입고관리( 구매처 ) · 입고검사 정책 · LOT 규칙( 거래처 요소 )

1003 공정관리 [완료]
  - 공정 등록 / 수정 · 구분 코드 · 공정별 사용 설비 후보 · 물림 손실
  - 시스템 공정 4종 ( 자동 생성, 생산 3단계에서 "완료만 처리" 예정 )
  - 엑셀 내보내기
  → 연결 : 설비관리 ( 설비 후보 ) · 공정라우팅관리 · 작업지시( 공정 · 설비 )

1004 설비관리 [완료]
  - 설비 등록 / 수정 · 엑셀 내보내기
  → 연결 : 공정관리 ( 공정별 설비 후보 ) · 작업지시 ( 지정 설비 )

1005 창고관리 [완료]  ※ 기능 스위치( 창고 ) 로 켜고 끔
  - 창고 트리( 다단계 로케이션 ) 등록 / 수정
  - 재고가 있는 창고를 내리면 경고 ( W_WH_HAS_STOCK )
  → 연결 : 입고 · 출고 · 재고현황 · 창고이동 · 재고조정

1006 공정라우팅관리 [완료]
  - 품목별 공정 순서 ( 끌어서 순서 변경 ) · 공정별 표준시간
  - 초 · 중 · 종 검사 개별 켜고 끄기 · 선행 진행 승인 설정
  - 저장 시 품목의 1개 생산 표준시간 다시 계산
  → 연결 : 품목관리 ( 기본 라우팅 ) · BOM관리 ( 자재 투입 지점 = 라우팅 줄 ) · 작업지시 ( 공정 복사 )

1007 BOM관리 [완료]  ※ 기능 스위치( BOM ) 로 켜고 끔
  - 품목별 BOM · 버전 · 활성 전환 · 변경일 · 변경 사유 · 승인 ( 기록용 )
  - 줄별 자재 · 소요량 · 투입 지점( 라우팅 공정 ) · 계산식 · 기능형 숫자 칸
  → 연결 : 품목관리 ( 주 자재로 자동 생성 ) · 공정라우팅관리 ( 투입 지점 )
           작업지시 ( BOM 사본 고정 ) · 자재출고 ( 계산식 소요 )

1008 검사항목관리 [완료]
  - 검사 항목 마스터 ( 항목명 유일 ) · 정량( 단위 ) / 정성( 판정 기준 )
  - 사용 중인 기준서 수 표시 · 기준서가 쓰는 항목을 내리면 경고
  - 엑셀 내보내기
  → 연결 : 검사기준서관리 ( 항목을 골라 복사 )

1009 검사기준서관리 [완료]
  - 품목 × 검사 종류( 입고 · 공정 · 출하 ) 별 기준서 · 사용 중 1개
  - 항목은 마스터에서 골라 넣거나 직접 입력 · 규격 · 하한 · 상한
  → 연결 : 검사항목관리 · 품목관리 · 입고검사 ( 공정 · 출하 검사는 개발 예정 )

1010 제조리드타임관리 [완료]
  - 기본값 1행 + 품목별 5구간( 구매 · 입고 · 생산 · 검사 · 포장 ) 일수
  - 엑셀 내보내기
  → 연결 : 품목관리 탭 4 ( 리드타임 표시 ) · 생산 4단계 부족 시점 계산 ( 예정 )

1011 LOT규칙관리 [완료]  ※ 기능 스위치( LOT ) 로 켜고 끔
  - 규칙 6종 ( 생산 4 · 출하 1 · 시리얼 1 ) · 조합 요소 · 고정 문자 · 구분자 · 날짜 3단계
  - 실시간 미리보기 · 출하 LOT 규칙이 없으면 경고 ( W_LOT_NO_SHIP_RULE )
  → 연결 : 입고관리 ( 입고 LOT 발급 ) · 작업지시 ( 생산 LOT 발급 ) · 출하 ( 예정 )

 3. 수주관리
================================================================================

2001 수주관리 [완료]
  - 수주 등록 / 수정 · 번호 SO-YYMMDD-NNN · 1수주 N품목 · 품목별 납품일
  - 상태 4단계 ( 기본 확정 ) · 마감 / 다시 열기
  - 삭제 ( 아래 단계가 있으면 취소로 ) · 작업지시가 붙은 줄은 품목 변경 · 삭제 잠금
  - 단가는 품목 판매단가로 채움 · 첨부 · 엑셀 내보내기( 줄 단위 ) · 공통 검색바
  → 연결 : 거래처관리( 고객사 ) · 품목관리 · 작업지시 ( 수주 줄 [작업지시] 버튼, 분할 / 병합 )

 4. 자재관리
================================================================================

3001 구매관리 [미개발]

3002 발주서관리 [완료]
  - 발주 등록 / 수정 · 번호 PO-YYMMDD-NNN · 구매처 · 자재 ( 제품은 경고 후 허용 )
  - 발주단가 · 입고 예정일 · 입고 진행 표시 · 입고된 줄 잠금
  - 첨부 · 엑셀 내보내기( 줄 단위 ) · [발주서] 엑셀 양식 출력
  → 연결 : 거래처관리( 구매처 ) · 품목관리 · 입고관리 ( 발주 입고 수량 · 자동 완료 )

3003 입고관리 [완료]
  - 입고 등록 ( 발주 없이도 가능 ) · 입고 LOT 발급 · 과입고 경고
  - 입고검사 정책에 따라 바로 재고 / 검사 대기 · 줄 취소 ( 재고 되돌림 )
  → 연결 : 발주서관리 · 입고검사 ( 같은 검사 완료 창 ) · LOT규칙관리 · 재고관리

3004 출고관리 ( 자재출고 ) [완료]
  - 작업지시 기준 자재 출고 · 계산식 소요( 절단 · 물림 손실 등 ) · 규격별 계산
  - 선입선출 / 잔재 우선 LOT 채움 · 줄 취소 · 출고 시 사용처리
  → 연결 : 작업지시 ( 자재 탭 [출고] → 이 화면 ) · BOM관리 ( 계산식 ) · 재고관리

3005 재고관리 ( 재고현황 ) [완료]
  - LOT 별 재고현황 · LOT 이력 창 · 엑셀 내보내기
  → 연결 : LOT 이력 창에서 [창고이동] · [재고조정] 으로 이동

3006 재고조정 [완료]
  - 센 수량 입력 → 증감 자동 계산 · 사유( ADJUST_REASON, 기타면 상세 필수 )
  - 조정 이력 · 취소
  → 연결 : 재고관리 ( 진입점 ) · 코드관리 ( 사유 )

3007 창고이동 [완료]
  - LOT 을 다른 창고로 이동 · 현재고 초과 막음 · 취소 ( 받은 창고 재고 확인 )
  - 이동 이력
  → 연결 : 재고관리 ( 진입점 ) · 창고관리

4006 작업지시 [완료]  ( 생산 1단계 + 작업지시서 )
  - 작업지시서 한 장에 품목 줄 여러 개 ( 여러 생산계획 · 여러 품목 ) · 번호 WO-YYMMDD-NNN / 줄 -01
  - 착수 · 기한 · 담당 · 비고는 지시서에 · 줄 취소 / 지시서 취소( 모든 줄이 대기일 때 )
  - 품목 줄마다 : 품목 · 공정 · 설비 후보 · 작업자 지정 · 생산 LOT
  - 라우팅 사본( 끌어서 공정 순서 ) · BOM 사본( 투입 지점 = 지시 공정 ) · 생산 LOT 발급
  - 수주에서 지시 · 분할 / 병합 · 진행 중 잠금 · 대기 상태만 취소
  - 출고된 지시는 자재 재복사 · 품목 변경 · 취소 막음
  - 첨부
  → 연결 : 수주관리 · 공정라우팅관리 · BOM관리 · LOT규칙관리 · 자재출고 ( 자재 탭 [출고] )
