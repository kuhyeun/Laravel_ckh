================================================================================
  MES Core 패키지 - Repo 분리 가이드
================================================================================

  현재 상태: 하나의 git에서 packages/mes-core를 로컬 패키지로 사용 중
  목표: mes-core를 별도 GitHub repo로 분리하여 Composer 패키지로 배포


================================================================================
  1단계: mes-core를 별도 GitHub repo로 push
================================================================================

  1-1. GitHub에서 새 Private Repository 생성
       - Repository 이름: mes-core
       - Private으로 생성

  1-2. mes-core 폴더를 별도 git으로 초기화 및 push

       cd packages/mes-core
       git init
       git add .
       git commit -m "MES Core 패키지 초기 버전"
       git remote add origin https://github.com/{your-org}/mes-core.git
       git push -u origin main

  1-3. 버전 태그 생성

       git tag v1.0.0
       git push --tags


================================================================================
  2단계: 업체 프로젝트의 composer.json 수정
================================================================================

  src/composer.json에서 path 방식을 vcs 방식으로 변경

  [변경 전]
  "repositories": [
      {
          "type": "path",
          "url": "../packages/mes-core"
      }
  ],
  "require": {
      "your-org/mes-core": "*"
  }

  [변경 후]
  "repositories": [
      {
          "type": "vcs",
          "url": "https://github.com/{your-org}/mes-core"
      }
  ],
  "require": {
      "your-org/mes-core": "^1.0"
  }

  변경 후 실행:
  composer update your-org/mes-core


================================================================================
  3단계: 새 업체 프로젝트 만들기
================================================================================

  3-1. GitHub에서 새 Private Repository 생성
       - Repository 이름: company-{업체명}-mes

  3-2. 현재 src/ 폴더 + Docker 설정을 복사하여 새 프로젝트 생성

       - src/ 폴더 내용을 새 repo 루트로 복사
       - 프로젝트 루트의 Docker/Nginx 파일도 함께 복사:
           Dockerfile           → company-a-mes/Dockerfile
           docker-compose.yml   → company-a-mes/docker-compose.yml
           docker-entrypoint.sh → company-a-mes/docker-entrypoint.sh
           nginx/               → company-a-mes/nginx/
       - vendor/, node_modules/ 제외
       - .env는 업체에 맞게 수정

       ※ docker-compose.yml 경로 수정 필요:
         [변경 전] ./src:/var/www/html
         [변경 후] .:/var/www/html

       ※ docker-entrypoint.sh의 심볼릭 링크 경로도 확인:
         packages/mes-core가 아닌 vendor/에서 Core를 가져오므로
         node_modules 심볼릭 링크가 불필요할 수 있음 (vite alias로 처리)

  3-3. composer.json에 mes-core 연결 (2단계와 동일)

  3-4. 설치 및 확인

       composer install
       npm install
       php artisan config:clear
       php artisan cache:clear


================================================================================
  4단계: 업체별 커스텀
================================================================================

  4-1. config/mes.php에서 업체에 필요한 모듈만 활성화

       'modules' => [
           'Order',          // 필요한 모듈만
           'Production',     // 남기고
           // 'Material',    // 불필요한건 주석처리
       ],

  4-2. app/Modules/ 에서 업체 전용 모듈 개발

  4-3. .env에서 업체별 DB, 환경 설정


================================================================================
  Core 업데이트 반영 방법 (일상적으로 반복하는 작업)
================================================================================

  [mes-core repo에서]
  - 코드 수정
  - git add . && git commit -m "설명"
  - git tag v1.0.1 (또는 v1.1.0)
  - git push && git push --tags

  [각 업체 repo에서]
  - composer update your-org/mes-core
  - 테스트 후 commit


================================================================================
  버전 규칙 (Semantic Versioning)
================================================================================

  v1.0.0 → v1.0.1   버그 수정 (patch)
  v1.0.0 → v1.1.0   기능 추가 (minor) - 하위 호환 유지
  v1.0.0 → v2.0.0   하위 호환 깨지는 변경 (major)

  composer.json에서 "^1.0" 으로 지정하면:
  - v1.0.1, v1.1.0, v1.9.9 → 자동 업데이트됨
  - v2.0.0 → 업데이트 안 됨 (수동으로 "^2.0" 변경 필요)


================================================================================
  현재 프로젝트 구조 참고
================================================================================

  packages/mes-core/          → 나중에 별도 repo (your-org/mes-core)
  ├── src/                    → namespace: MesCore\
  │   ├── Auth/               → 인증/권한
  │   ├── Menu/               → 메뉴 시스템
  │   ├── Http/               → Base Controller, Inertia
  │   ├── Basic/              → 기준정보관리
  │   └── CoreServiceProvider.php
  ├── resources/js/           → Core 프론트엔드
  ├── config/mes.php          → 기본 설정
  └── composer.json

  src/                        → 업체 프로젝트 (your-org/company-{업체명}-mes)
  ├── app/Modules/            → 업체 전용 모듈
  ├── config/mes.php          → 업체별 모듈 on/off (Core 설정 오버라이드)
  ├── resources/js/           → 업체 전용 화면
  └── composer.json           → requires "your-org/mes-core"
